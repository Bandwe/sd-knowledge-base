# 主要剧作框架对照：该用什么，不该怎么套

> 使用边界：以下是创作与改稿工具，不是每个项目的强制步骤。开发阶段可以提出方案；剧本锁定后，人物关系、事件顺序、关键动作及逐字对白只按作者已确认的修改调整。时长、页数、集数、评分和训练数量均为工作示例，不是模型能力或作品质量保证。


结构框架回答的是不同问题。把它们叠成一张超级节拍表，往往会让剧本僵化。

更完整的逐书结论见[剧作书籍方法对照](16-剧作书籍方法对照.md)，证据边界见[方法适用边界](15-剧作方法的证据与适用边界.md)。

| 框架/作者 | 最擅长回答 | 适合阶段 | 误用风险 |
|---|---|---|---|
| Aristotle | 行动是否完整，反转和高潮是否由因果产生 | 概念、终稿诊断 | 只记“开中结”，忽略选择与情感效果 |
| Egri | 前提如何通过人物矛盾和冲突得到证明 | 人物、主题 | 把前提写成口号，让角色替作者辩论 |
| Syd Field | 长片宏观三部分和方向变化是否清楚 | 第一版大纲 | 把页码当法律，所有电影长得一样 |
| Blake Snyder | 商业片承诺、节奏和中段是否缺关键功能 | 节拍表、节奏诊断 | 先填十五格再找人物，产生公式感 |
| McKee | 每场戏是否发生价值转变，冲突是否升级 | 分场、改稿 | 每场强行反转，失去自然呼吸 |
| Truby | 情节如何从人物网络、道德论证和世界生长 | 深度开发 | 二十二步全部显性化，开发过重 |
| Vogler | 主角跨越心理门槛的成长过程 | 神话、冒险、成长类型 | 把所有故事写成单一英雄单线 |
| Gulino 序列法 | 长片中段如何由一组局部目标持续推进 | 分段、场景卡 | 八段平均用力，缺少整体高潮 |
| John Yorke | 五幕对称、转折与认知变化 | 结构复盘 | 把对称误当成机械镜像 |
| Dramatica | 客观、主角、影响角色、关系四条压力是否完整 | 复杂故事诊断 | 术语先行，人物被分类表绑架 |
| Cowgill / Cooper-Dancyger | 短片如何压缩人物、时间、地点和变化 | 独立短片 | 只追求小，失去真正转折 |
| Douglas / Sandler / Epstein / Landau | 系列引擎、试播集、集故事和编剧室如何运转 | 电视剧开发 | 把行业惯例当永恒格式，忽略地区差异 |
| 中文微短剧新教材 | 竖屏、平台、网文改编和本土生产如何结合 | 微短剧开发 | 追热点公式，忽略人物和长期品牌 |

## 一、选择框架的简单规则

### 如果你只有灵感，没有故事

先用 Egri/Truby 的人物矛盾问题，加 Aristotle 的因果问题。暂时不要填节拍表。

### 如果你有完整故事，但中段很散

用序列法拆局部目标，再用 McKee 检查每个序列内部的场景价值变化。

### 如果你有很多事件，但人物没感觉

用 Truby 的人物网络、McKee 的压力下选择、Dramatica 的主角/影响角色/关系三条线检查。

### 如果商业类型片节奏失控

用 Field 看宏观方向变化，用 Snyder 看功能是否缺位。百分比只作诊断参照，不反过来支配故事。

### 如果电视剧第一集好看，后面没得写

停止研究电影节拍，改做系列引擎、关系矩阵和 20 集故事压力测试。

### 如果短剧每集都有反转但越来越无聊

检查单元升级、关系状态和信息增量。减少撤销式反转，增加由选择产生的后果。

## 二、同一故事的四种观察尺度

用任何框架都要同时看四个尺度：

1. **全片/全季**：核心问题和高潮结算。
2. **幕/单元/序列**：阶段目标与不可逆变化。
3. **单集/场景**：人物目标、阻力、转折和后果。
4. **节拍/台词/动作**：策略如何一招一招变化。

上层没有方向，下层越精致越浪费；下层没有行动，上层结构只是提纲。

## 三、统一诊断语言

不同书籍术语不同时，统一翻译为：

- `目标`：人物现在想让什么发生。
- `阻力`：谁或什么积极阻止。
- `策略`：人物为目标采取的办法。
- `转折`：新事实或行动改变局面。
- `价值变化`：自由/受困、亲密/疏离、信任/怀疑等状态改变。
- `代价`：人物为了前进失去或冒险什么。
- `选择`：两个有意义方案之间的价值排序。
- `后果`：选择如何制造下一段故事。

用统一语言讨论，能避免团队因为“三幕还是五幕”“中点还是第二转折”争论名词而不解决剧情。

## 四、框架使用纪律

- 初稿前只选一个主框架。
- 其他框架只回答特定问题。
- 不因某个节拍晚了两页就硬改，先看观众体验是否真的迟滞。
- 不让人物为了抵达节拍做违背已建立逻辑的事。
- 理论冲突时，以作品的核心矛盾、媒介、类型和真实阅读/观看反馈为准。
- 任何结构修改都记录它解决的具体问题，避免“看起来更专业”的无效返工。
