# 短剧钩子与分集

短剧不是把长剧平均切碎。每集需要清楚的主问题、行动、增量和落点，整季仍需要人物选择与因果累积。

## 三种短内容分别设计

独立短片一次完成核心变化；连续微短剧在局部满足之外推动季主线；单条剧情短视频通常需要独立理解。先确认媒介，再谈节奏与长度。

## 单集的最小链条

承接上一后果 → 当前目标 → 主动阻力 → 新信息或关系变化 → 局部结算 → 新不平衡。

每集只锁一个主要问题。高能可以是一个选择被看见、一次关系退让或一条证据改变计划，不必每集都吵、哭、打或反转。

## 五类钩子

| 类型 | 观众等待什么 | 有效条件 |
|---|---|---|
| 信息 | 一个明确问题的答案 | 前文有可追溯线索，揭晓改变行动 |
| 关系 | 两人的距离或立场如何变化 | 有真实经历和相互选择支撑 |
| 选择 | 人物会付出哪一种代价 | 两种选择均有意义，不能假两难 |
| 危机 | 怎样应对已经逼近的风险 | 空间、时间、资源条件清楚 |
| 承诺 | 人物能否兑现已经承担的责任 | 下一段真正检验承诺，不仅口头宣布 |

镜头突然停止不是钩子的充分条件。下一集开头先支付上一集的期待，再打开新问题；反复撤销已发生的结果会损害观众信任。

## 时长由内容承载量决定

例如 3—5 分钟单集可以在开头迅速接入冲突，中部推进信息与关系，末段完成一次转折并留下新问题。这个范围只是某类规格的示例，不是所有 AI 短剧的标准。

90—120 秒或更短内容可以更早展示异常，但“开场几秒必须怎样”不应覆盖所有风格。先用朗读和动作排练估时，再决定分集，不用解释性对白补长度。

## 长短版本共用因果骨架

若需要两种剪辑长度，先标出不可删除的因果节点、关系经历和必要线索。长版可保留更多呼吸与余波，短版收紧重复信息；不能因切点而改变人物为何行动。

## 避免中段重复

把整季分成若干阶段，每阶段更换目标条件、关系状态或对手策略。升级不是只增加更强对手或更重羞辱。角色每次行动应带来新责任、暴露或损失，不能下一集自动重置。

## 分集检查表

- 本集主要问题与上一集后果相连吗？
- 人物有主动行动和新的选择吗？
- 有没有只有热闹、没有后果的高光？
- 钩子是否真实改变下一集条件？
- 小屏观看能否读懂关键动作与线索？
- 连续三集是否重复同一种解决办法？
- 删掉本集，会损失哪一项信息、关系或体验？

制作与发布规范可能变化，正式发行按实际地区和平台核对。本篇只保留创作方法，不把历史政策快照作为现行结论。
