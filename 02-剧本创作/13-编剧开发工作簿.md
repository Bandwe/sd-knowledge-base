# 编剧开发工作簿：电影、电视剧、短剧通用模板

> 使用边界：以下是创作与改稿工具，不是每个项目的强制步骤。开发阶段可以提出方案；剧本锁定后，人物关系、事件顺序、关键动作及逐字对白只按作者已确认的修改调整。时长、页数、集数、评分和训练数量均为工作示例，不是模型能力或作品质量保证。


使用方式：复制需要的章节到项目目录，先用短句填完，再扩写。空白项不是为了形式完整，而是暴露尚未解决的问题。

## 模板 2：一句话故事压力测试

```markdown
当【触发事件】发生后，
一个【具体身份 + 矛盾特征的主角】
必须在【时限/环境】内完成【可观察目标】，
否则【外在 + 关系 + 内在代价】；
但【主动对手/制度/环境】不断用【主要压力方式】阻止他，
而他坚持的【错误生存方式】让一切越来越糟。
最终他必须在【选择A】与【选择B】之间作出有代价的决定。
```

检查：

- 去掉专有名词，冲突仍然清楚吗？
- 主角是否必须行动？
- 目标是否能被拍出来？
- 对手是否会主动反制？
- 失败代价是否具体？
- 高潮是否隐约包含在概念里？

## 模板 12：对白改写表

```markdown
| 原台词 | 说话目标 | 言语动作 | 表面意思 | 潜台词 | 可否改动作 | 角色声音特征 | 改写 |
|---|---|---|---|---|---|---|---|
| | | | | | | | |
```

删改顺序：

1. 删除双方都知道的背景。
2. 删除刚被画面证明的解释。
3. 删除连续重复同一情绪的句子。
4. 把直接答案改成策略、回避或反问。
5. 用反应和停顿替换部分台词。
6. 最后才追求金句。

## 模板 14：改稿问题单

```markdown
| 优先级 | 问题 | 证据场景 | 根因假设 | 解决方案A | 解决方案B | 采用方案 | 验证方式 |
|---:|---|---|---|---|---|---|---|
| P0 | | | | | | | |
```

优先级：

- `P0`：核心因果、人物动机、高潮或媒介定位不成立。
- `P1`：结构、节奏、关系弧光和关键信息分配问题。
- `P2`：场景功能、对白、视觉表达和连续性问题。
- `P3`：措辞、格式、标点和轻微润色。

先修 P0，再修 P1。否则页面润色会被下一轮结构修改全部推翻。

## 模板 15：完整剧本自评表（100分）

| 维度 | 分值 | 评分问题 |
|---|---:|---|
| 概念与媒介匹配 | 10 | 为什么必须用这种媒介讲？ |
| 主角主动性 | 10 | 主角是否持续选择并制造后果？ |
| 对手与阻力 | 10 | 阻力是否主动、升级、能反制？ |
| 因果与结构 | 15 | 主要变化是否由前因推出？ |
| 人物与关系 | 15 | 关系是否积累、改变、影响主线？ |
| 场景转折 | 10 | 场景前后是否有实质变化？ |
| 视觉表达 | 10 | 重要内容能否被看见和表演？ |
| 对白与声音 | 10 | 台词是否有目标、潜台词和人物差异？ |
| 节奏与情绪 | 5 | 是否有升级、对比和必要呼吸？ |
| 兑现与余波 | 5 | 结尾是否结算主要承诺？ |

低于 70：回到结构和人物；70—84：集中修场景与关系；85 以上：进行朗读、制作可行性和细节打磨。
