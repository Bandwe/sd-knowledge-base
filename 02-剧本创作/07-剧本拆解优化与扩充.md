# 剧本拆解、优化与扩充

本篇仅提炼可复用的改稿方法，不保留原讨论、项目情节和会议发言。判断一处问题与决定采用哪种创意方案是两个阶段。

## 先判断故事能否持续

设定有趣不等于已经有故事引擎。继续问：主角为何必须行动，什么场域迫使相关人物持续相遇，目标如何产生不同阻力，成功为何带来新的后果。若中段只能不断制造偶遇，应先补关系条件和行动理由。

## 人物的选择需要具体根据

善良、聪明、坚强只是概括。能力需要通过解决问题的过程呈现，吸引需要通过双方重视的经历成立。共同经历、价值认同或互补都可能有效，不把一种关系公式套给所有人。

重新建立信任需要新的行动；知道身份或听到解释，不能自动替代人物对旧问题的回应。

## 世界规则与知情条件分开管理

明确哪些规则稳定、何时改变、变化带来什么限制。再区分真实事实、每个角色的认知和观众已知信息。误会应来自不同的证据和判断，不依赖人物突然不问、不说、不记得。

线索可以经历发现异常、形成怀疑、验证和决定是否说破。每一步要有行动条件；不能只因“很像”就跳过全部确认过程，也不必让所有类型都采用同一种证明强度。

## 优先修因果，再润色台词

对每段写：因为什么，此人想做什么；他采用什么办法，遇到什么阻力；结果改变了什么，又迫使下一步怎样行动。若相邻场只有时间先后而没有条件变化，再多漂亮台词也难以补牢。

## 心理变化必须有经历

把“他终于理解”拆成旧认识、新证据、矛盾体验和新的选择。新认识出现在何种压力之后，会改变同一场戏的意义。最终需要在有代价时看到新行动，而不只听见一句道歉。

## 扩充的四种尺度

1. 单场跳跃：补足关键行动、接触和反应。
2. 相邻场断裂：补必要的判断、准备或后果。
3. 冲突过快解决：展开不同策略与代价。
4. 中段缺少推动：再考虑能影响主线选择的副线。

不因篇幅短就立即新增人物、职业或世界体系。先证明原有人物怎样行动，明确成功影响了谁、失败改变了什么，以及为何需要合作。

主角主动不等于主角独自完成一切。其他角色可以提供关键帮助，只要主角仍作出重要选择并承担后果，对方也有自己的判断。

## 判断是否注水

移除一场后，观察行动理解和情绪经验是否受损。没有新情节但改变关系的安静相处仍可能必要；信息密度也不等于每场同时塞满笑点、线索、甜蜜和反转。

新增场景前写清承接什么、改变什么、删掉后哪一步难以理解。说不清时先不要加。预告片高光不能证明连续正片成立，应检查两段亮点之间的选择与后果。

## 改稿顺序

当前采用稿与不可改项 → 核心目标和故事引擎 → 世界规则与知情条件 → 因果链 → 心理经历 → 必要扩充 → 篇幅与对白 → 制作可行性。

完成后同时检查原问题与副作用：是否让主角被动、抹平独特声音、破坏后续铺垫、引入新矛盾。个人偏好、文本事实和待验证假设分开记录，不把候选方案拼成未经选择的综合版。
