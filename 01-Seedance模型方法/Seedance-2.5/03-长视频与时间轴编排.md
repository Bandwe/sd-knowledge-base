# 长视频与时间轴编排

资料性质：2026 年 8—9 月整理的说明页截图及创作笔记。保留方法，移除具体项目执行记录；不把历史资料表述为当前能力保证。历史规格见[参数快照](../历史资料与待核实参数.md)。


## 1. 30秒视频的三模块结构

历史说明页建议先用一句话概括整段视频，再展开三个模块：

```text
总述名称：一句话描述整个视频的基调

模块一：多模态参考层
模块二：全局设定层
模块三：时间轴脚本层
```

## 2. 模块一：多模态参考

当上传参考图、参考视频或参考音频时，先说明：

```text
基于上传的[参考素材类型]，严格保持[需要一致的内容]，严格锁定[不能变化的内容]。
```

素材可以在全文中多次引用，但每次引用都应说明用途。例如：

- 参考图锁定人物脸和服装；
- 另一张图锁定场景结构；
- 参考视频只参考动作速度和镜头高度；
- 参考音频锁定音色或节奏。

不要写笼统的“参考所有素材”，否则素材之间发生冲突时模型无法判断优先级。

## 3. 模块二：全局设定

原资料结构可整理为：

```text
[基础环境与质感]
+ [视觉风格]
+ [镜头语言]
+ [人物造型]
+ [表演核心]
+ [禁止项]
```

### 基础环境与质感

```text
[时间] + [地点] + [氛围] + [真实物理质感要求]
```

### 视觉风格

```text
[电影感/写实/一镜到底等] + [景深控制] + [打光方式]
```

### 镜头语言

```text
[景别/视角] + [摄影机运动和画面变化的详细描述]
```

### 人物造型

可引用人物素材，也可使用[人物公式](02-人物外观与表演公式.md)描述年龄、皮肤、五官、发型、服装和气质。

### 表演核心

说明整段表演最重要的情感重点，例如压抑、迟疑、逐渐失控、假装镇定。具体动作仍放入时间轴，不要只靠抽象情绪词。

### 禁止项

明确列出不要出现的声音、文字、行为、错误动作或多余内容。例如：

```text
禁止新增旁白与额外对白，禁止配乐与字幕，禁止无理由的大幅肢体动作，禁止情绪结果提前出现。剧本原有旁白按要求保留；是否快速剪辑由本镜头的表达目标决定。
```

## 4. 模块三：时间轴脚本

每个时间段的原资料结构：

```text
[开始秒数–结束秒数] + [核心阶段/主题]
[动作/表情等物理层面指令]
[情感解析或镜头调度等深层表达]
```

其中：

- 核心阶段：这一段在叙事上做什么；
- 物理指令：景别、构图、动作、表情、人物与环境互动；
- 深层表达：解释这些动作要传达什么，避免模型只机械执行动作。

示例骨架：

```text
【情绪与动作分镜（0–29秒）】

第一阶段 0–4秒｜建立空间和初始关系
动作/表情：……
情感解析：……

第二阶段 4–11秒｜刺激发生，人物开始反应
动作/表情：……
镜头调度：……

第三阶段 11–20秒｜关系升级或关键动作
动作/表情：……
情感解析：……

第四阶段 20–29秒｜结果与结束状态
动作/表情：……
镜头调度：……
```

时间段必须连续，不重叠、不留空，并且完整覆盖当前单元的目标时长。

## 5. 一镜到底与切换/转场

历史案例同时展示了“一镜到底”和“切换/转场”两类写法，说明30秒不要求固定采用某一种结构：

- 一镜到底：重点写清连续空间、人物动线、摄影机路径和每阶段焦点变化；
- 切换/转场：重点写清每次切换带来的新地点、新主体、新动作或新信息，以及转场触发方式；
- 无论采用哪一种，都要先锁定全局世界观、人物和禁止项。

## 6. 超长视频公式

截图给出的总体结构为：

```text
完整提示词 = [全局参数]
           + [素材描述]
           + [一句话概述]
           + [具体情节描述]
           + [全局补充（结尾）]
```

与基础公式相比，超长视频把“全局参数”放在最前面，用于先声明生成时长、帧率或其他全片设置；其余素材职责、情节时间轴、正向/反向描述和结尾锁定方式保持一致。


## 7. 使用边界

- “30 秒”是原资料组织长视频时的示例尺度，必须先确认当前模型与入口允许的时长，不能把示例写成所有任务的默认。
- “超长”首先是一种全片编排方式，可能需要多个单元、延长或后期拼接；标题本身不证明能够一次生成任意长度。
- 身份、对白、站位和物理互动复杂时，可以拆成较短单元。每段保留完整句子和可恢复的动作状态。
- 全局信息与参考职责写清一次即可；每段重点写新增动作、信息、反应和结束状态。
