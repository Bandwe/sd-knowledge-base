# 基础提示词的四段公式

资料性质：2026 年 8—9 月整理的说明页截图及创作笔记。保留方法，移除具体项目执行记录；不把历史资料表述为当前能力保证。历史规格见[参数快照](../历史资料与待核实参数.md)。


## 1. 历史资料中的四段公式

```text
完整提示词 = [素材描述] + [一句话概述] + [具体情节描述] + [全局补充（结尾）]
```

## 2. 素材描述

写法：

```text
素材编号（按上传顺序） + 该素材在视频中的具体用途
```

用途要说明该素材用于锁定什么，例如：

- 人物身份或外貌；
- 音色或声音；
- 动作节奏；
- 场景或环境；
- 镜头运动或转场方式。

没有参考图、参考视频或参考音频时可以省略。上传多个素材时，应逐一说明职责，避免让同一素材同时承担互相冲突的功能。

示例结构：

```text
@Image 1锁定人物A的脸、发型和服装；
@Image 2锁定人物B；
@Image 3锁定场景结构；
@Video 1只参考走路速度与身体重心，不继承人物外貌；
@Audio 1锁定人物A的音色。
```

## 3. 一句话概述

历史资料中的结构：

```text
主体 + 地点 + 事件 + 题材/风格 + 特殊运镜等
```

它负责让模型先理解整段视频的核心，不承担逐秒动作细节。

示例：

```text
人物A在雨夜走廊听见门后异响，克制地停步观察，采用悬疑电影风格与稳定轴线摄影。
```

## 4. 具体情节描述

可以按时间轴或分镜段落组织。每个时间段/镜头包含：

```text
正向描述 = 画面具体内容 + 运镜 + 动作 + 台词 + 音效
反向描述 = 不希望生成的元素
```

正向描述回答：

- 画面里是谁、在哪里；
- 摄影机从什么位置看；
- 谁先做什么，动作如何完成；
- 谁说哪句台词，谁负责反应；
- 环境中听见什么声音。

反向描述用自然语言写进提示词，例如：

```text
禁止额外人物，禁止新增台词，禁止字幕，禁止水印，禁止配乐。
```

## 5. 全局补充

放在提示词结尾，统一约束整段视频：

- 世界观与真实物理质感；
- 场景结构与环境特征；
- 整体镜头语言；
- 主体人物与参考素材一致性；
- 全片不能变化的状态；
- 全局声音和禁止项。

重要要求可以在这里再次强调，但不要用大量同义句重复，避免挤占真正的动作信息。

## 6. 可直接复用的基础模板

```text
【素材描述】
@Image 1用于……；@Image 2用于……；@Video 1只参考……；@Audio 1用于……。

【一句话概述】
<主体>在<地点>经历<事件>，整体为<题材/风格>，采用<特殊镜头语言>。

【具体情节】
[00:00-00:04] <画面与构图>；<人物动作、表情、视线和重心>；<台词>；<声音>。
[00:04-00:09] <新的叙事信息与动作>。
[00:09-00:15] <结果、反应与结束状态>。

【全局补充】
<场景结构、人物一致性、真实物理、色彩、光线、声音和禁止项>。
```

## 7. 与AI漫剧提示词的关系（项目映射）

项目中的“0秒站位＋逐镜四字段＋结尾状态”并不违背历史资料中的公式，而是对其进行结构化：

| 历史资料中的模块 | 项目对应部分 |
| --- | --- |
| 素材描述 | 人物、场景、道具、色卡资产绑定 |
| 一句话概述 | 本单元唯一叙事任务与风格 |
| 具体情节 | 连续时间轴及每镜“镜头/运镜/表演/人物状态” |
| 全局补充 | 站位、行动轴、声音、禁止项、结束状态 |

本库的声音约束为“无配乐、无字幕，保留剧本所需对白、原有画外音与物理环境音”。这是制作约定，并非模型强制语法。
