# 人物外观、材质与表演公式

资料性质：2026 年 8—9 月整理的说明页截图及创作笔记。保留方法，移除具体项目执行记录；不把历史资料表述为当前能力保证。历史规格见[参数快照](../历史资料与待核实参数.md)。


## 1. 总公式

```text
人物 = [年龄/种族]
     + [肤色/皮肤质感]
     + [面部细节特征]
     + [眼神/灵魂]
     + [发型/发色]
     + [服装/服装质感]
     + [体型/情绪/气质]
     + [其他要求（如有）]
```

这套公式的目的不是堆砌华丽形容词，而是用可观察的细节降低“AI塑料感”和双胞胎式同质脸。

## 2. 年龄与种族

结构：

```text
[具体岁数] + [具体国籍/人种] + [风格形容词] + [脸型或骨骼形容词]
```

不要只写“年轻女性”或“中年男人”。应明确年龄段、地域/人种特征和骨骼方向，例如清秀、硬朗、高颧骨、立体骨骼等。

## 3. 肤色与皮肤质感

结构：

```text
[肤色调] + [具体肤色名称] + [皮肤质感]
+ 保留真实的细微毛孔与肌肤纹理
+ 可选：雀斑、晒痕、细纹或轻微瑕疵
```

原学习笔记强调不要用单一“苍白”替代真实皮肤。皮肤应有暖冷倾向、透光或粗糙程度，并保留真实纹理，避免蜡像感。

## 4. 面部细节

结构：

```text
[眼型] + [眉骨] + [鼻梁] + [唇形] + [下颌线/颧骨]
```

建议至少选择3–4个清楚特征。描述要能被画面观察，例如：

- 眼睑形状、眼距、眼尾方向；
- 眉骨高低和眉峰；
- 鼻梁直度、鼻尖与鼻翼；
- 唇峰、嘴角和唇厚；
- 下颌线、颧骨和面部轮廓。

## 5. 眼神与“灵魂”

结构：

```text
[眼神形容词] + [目光传达的信息或比喻] + [底层情绪]
```

眼神描述不能只写“有神”。需要同时交代：

- 目光是否聚焦、警惕、游移、空洞或疲惫；
- 看向谁或什么；
- 角色试图隐藏或传达的底层情绪。

## 6. 发型与发色

结构：

```text
[具体发色] + [头发状态/质感] + [具体发型] + [环境互动]
```

环境互动例如：被风吹乱、被雨水打湿、发丝贴在额头、碎发随走动轻晃。发型应与人物身份和当下状态一致。

## 7. 服装与材质

结构：

```text
[版型/剪裁] + [颜色] + [具体服装] + [布料材质/新旧状态] + [穿着方式/细节]
```

服装描述要覆盖轮廓和物理质感，例如：

- 修身或宽松；
- 羊毛、丝绸、棉、皮革等材质；
- 新、旧、磨损、潮湿、沾灰；
- 扣合、敞开、卷袖、衣摆随风等穿着细节。

## 8. 体型、情绪与气质

结构：

```text
[骨架/肩部特征]
+ [构图/镜头要求]
+ [人物动作/视线]
+ [整体氛围]
```

这部分决定人物在画面中的力量感和故事感，例如：

- 肩背宽窄、身形修长或敦实；
- 胸像、半身、全身、低机位或面部特写；
- 正视镜头、回避视线、身体前倾或后撤；
- 温柔、危险、疲惫、权威、神秘等整体气质。

## 9. 合并模板

```text
[年龄与身份]，具有[骨骼与脸型]。
[肤色调与皮肤质感]，保留细微毛孔、纹理和真实瑕疵。
[眼型、眉骨、鼻梁、唇形、下颌/颧骨]。
眼神[可观察状态]，目光看向[目标]，底层压着[情绪]。
[发色、发型、质感]，发丝与[风/雨/动作]产生真实互动。
穿[版型、颜色、具体服装、材质与状态]。
[体型与肩背]；采用[构图和视角]；人物[动作与视线]；整体呈现[气质]。
```

## 10. 使用现成人物资产时的边界（项目建议）

当参考图已经锁定角色时，不要重新写一套互相冲突的五官。提示词应分为：

- 由参考图锁定：脸、发型、基础服装、年龄外观；
- 由文字补充：当前伤势、汗水、妆容、情绪、微表情、衣料状态、光线和动作；
- 绝不能改变：角色身份映射、伤势左右、服装版本和剧情状态。

这段是项目应用建议，不是模型必须遵循的强制规则。
## 动画人物的使用

该结构也可用于动画人物，但皮肤、五官与材质描述必须服从既定画风；不要把写实毛孔、真实肤质等要求自动带入风格化角色。先保留身份辨识点，再补当前表演与环境互动。
