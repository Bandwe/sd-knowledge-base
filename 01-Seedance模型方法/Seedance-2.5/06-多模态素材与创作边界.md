# 多模态素材与创作边界

资料性质：将历史截图中的输入建议与制作经验分开整理。关于素材数量的历史数值见[参数快照](../历史资料与待核实参数.md)，本页不把容量上限当成最佳配方。

## 素材越多，不代表越稳定

1. 只保留当前单元有明确职责的素材。
2. 按实际素材顺序写清身份映射，避免文字编号和画面对象不对应。
3. 人物图锁身份；服装图锁造型；场景图锁空间；道具图锁物件；色卡只锁颜色。
4. 动作视频写明继承的速度、重心、动作顺序或摄影机运动，同时排除其中人物外貌和服装。
5. 音频只承担指定音色、对白感觉或环境声职责；不要自动继承音乐和无关台词。
6. 主体过多、拼图视角太多或素材相互冲突时，先减少素材并明确优先级。

历史截图倾向于少量、清晰的主体参考；多主体时，单图里挤入多个视角容易增加理解负担。采用多视角时要说明它们属于同一个角色，成片中不是多个人。

## 从四段公式落到分镜

| 提示词层 | 制作内容 |
| --- | --- |
| 素材描述 | 身份、场景、道具、色卡的绑定和职责 |
| 一句话概述 | 本单元唯一叙事任务与风格 |
| 具体情节 | 开场站位、连续时间轴、镜头与表演 |
| 全局补充 | 行动轴、保持项、声音、禁止项、结束状态 |

分镜可以用“镜头、运镜、画面与人物表演、人物状态”四字段，也可以按当前镜头改用自然语言段落。格式可换，必要的空间、动作、表演、时序与声音信息不可缺。

## 较短单元更值得考虑的情况

- 逐字对白多或有多名说话者；
- 需要严控屏幕左右、角色自身左右、手部归属和行动轴；
- 道具交接、推搡、跌倒、伤势变化或近身互动集中出现；
- 下一段必须根据实际成片重新确定起始状态。

## 较长单元可以尝试的情况

- 主体少，空间和时间连续；
- 单一行为或少量逻辑明确的切换；
- 动作轨迹清楚，阶段目标可以完整写进时间轴；
- 不需要把过多身份、接触和状态变化同时锁定。

这只是内容风险判断，不承诺长或短必然更稳定。

## 文字状态传递

从最后一个可读全景或中全景建立人物与固定环境的关系，再从片尾更新可见的表情、视线、手部和道具状态。特写裁掉的部位记为未知，不猜测。

下一单元的开场写成自包含描述，不只写“接上条”。普通外观参考、首帧、尾帧和参考视频按当前项目选择；不能未经选择就把前一尾帧自动升级为下一段首帧。

## 压缩提示词的方法

- 删除同义反复，不删除剧情锁。
- 每镜保留主要叙事任务，复杂动作拆成能观察的阶段。
- 素材职责集中写一次；必要硬锁在末尾简短重申。
- 用视线、停顿、呼吸、重心和接触替代连续堆砌抽象情绪词。
- 更长的输入容量意味着可表达更完整的关系，不意味着每条提示词都要写满。
