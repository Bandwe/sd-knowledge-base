# 短剧单元准备卡

资料性质：由历史使用手册中的短剧接入检查卡整理，只保留创作准备与成片判断。

## 使用时机

- 规划多模态素材职责和当前单元；
- 编写自包含提示词；
- 决定新生成、延长、编辑、角色替换或一镜到底；
- 比较成片与剧本、参考素材、动作目标。

剧本创作阶段不能让展示案例反向改写已锁定剧情。

## 创作顺序

剧本与事件顺序锁定 → 人物、场景、道具资产确定 → 选择表达方式 → 建立素材职责表 → 自包含提示词 → 检查时间、动作与声音 → 版本对比与用户采用。

## 准备五问

1. 每个素材是否职责明确？素材之间冲突时，以哪份为准？
2. 动作、对白与听者反应能否自然完成，是否需要拆分？
3. 延长是否说明真实尾部状态和新增内容？
4. 编辑是否说明修改区间、保持项和修改后的衔接？
5. 人物、声音、道具和画面风格是否符合当前项目要求？

## 忠实制作的边界

保留剧情、事件顺序、人物关系和台词，只细化表演、时序、摄影和可见物理细节。不因模型展示效果而新增角色、转场、对白或音乐。

## 模式选择

| 需求 | 优先模式 | 不适合的情况 |
| --- | --- | --- |
| 从锁定资产生成新剧情单元 | 多模态新生成 | 已有片段只需局部小修 |
| 从上一段真实结尾继续 | 延长 | 原片身份、站位或剧情已经错误 |
| 只改一段动作或表演 | 局部编辑 | 大部分剧情或场景都需重写 |
| 换角色，保留动作与镜头 | 角色替换 | 遮挡、接触与身体比例不适配 |
| 连续空间运动 | 一镜到底 | 信息过密，复杂互动无法清楚表达 |

## 结果记录

技术层面记录文件能否解码、时长、分辨率、帧率、音轨与异常截断。创作层面比较剧情、对白、素材职责、身份、道具、场景、动作、镜头和结束状态。

保存提示词版本、素材职责、结果与用户采用结论。单次成功只作为一个案例，不直接升级为所有项目的默认规则。具体修改另存版本，创意取舍由使用者决定。
