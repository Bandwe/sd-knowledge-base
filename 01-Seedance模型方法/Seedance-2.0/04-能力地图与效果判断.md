# 能力地图与效果判断

资料性质：2026 年 9 月整理的使用手册学习笔记。以下是创作写法与当时的界面语义，不代表当前版本的功能保证。历史数量、时长和格式限制见[参数快照](../历史资料与待核实参数.md)。

手册的大部分篇幅是案例表。知识库只提炼“参考职责与任务结构”，不复制案例的完整品牌、人物、对白或专有内容。

## 证据等级

| 等级 | 含义 | 能否作为生产默认 |
| --- | --- | --- |
| 手册导语 | 产品方文字描述 | 不能；只代表文档陈述 |
| 手册案例 | 文档展示了输入与结果文件名 | 不能；没有本次复现 |
| 本地离线推演 | 能把案例改写成可检查提示词 | 不能；仍无生成证据 |
| 单次实测 | 一个任务在一个入口成功 | 只能作为单案例证据 |
| 多任务复现 | 不同素材、不同任务稳定成功 | 才可考虑升级为默认方法 |

本库当前最高只到“本地离线推演”。

## 能力地图

| 手册主题 | 可复用方法 | 首要验收 |
| --- | --- | --- |
| 基础真实感 | 写清物理接触、重心、惯性和环境反馈 | 滑步、漂浮、穿模、动作突变 |
| 一致性 | 分开锁定人物、服装、商品、文字、场景和风格 | 前后身份、文字、商品细节、场景布局 |
| 运镜与动作复刻 | 视频只承担运镜／动作职责，图片承担身份／场景职责 | 是否误继承参考视频人物；镜头是否少段 |
| 创意模板与复杂特效 | 指定只参考节奏、转场、视觉结构或特效 | 是否变成近似复制；品牌与版权风险 |
| 剧情补全 | 提供图序、分镜脚本、声音或一句话主题 | 是否擅自改剧情、顺序、台词和关系 |
| 视频延长 | 从真实尾部状态继续，生成时长等于新增时长 | 重复、回跳、接缝、声音断裂 |
| 音色与声音 | 区分音色、说话动作、语言内容、环境音和音乐 | 音画同步、说话者、台词准确、底噪 |
| 一镜到底 | 用连续路线、遮挡和空间锚点描述镜头 | 假切镜、瞬移、方向反转、空间折叠 |
| 视频编辑 | 标明修改片段与全局保持项 | 未指定内容被重写 |
| 节奏与后期卡点 | 分镜规划关键动作，配乐与卡点在后期组织 | 动作落点、镜头信息和段落节奏 |
| 情绪演绎 | 参考表情强度与动作链，而非只写抽象情绪 | 夸张、错位、情绪无因果、表情跳变 |

## 1. 一致性

手册展示人物、服装、商品细节、小字、场景和镜头风格的一致性案例。

本地采用法：

- 人物、服装、道具和场景分开绑定素材；
- 对小字和品牌标识单独验收，不因人物一致就判整条通过；
- 多场景任务先写场景转换关系，不让模型自行猜空间；
- 写清谁必须保持、什么可以变化。

## 2. 运镜与动作复刻

手册的核心思想不是再写一遍复杂运镜，而是上传参考视频后说明“完全参考什么、不要继承什么”。

审核拆成两条：

1. **动作忠实度**：动作顺序、速度、重心、接触和反应；
2. **摄影忠实度**：机位、轨迹、焦距变化、摇移方向、切换节奏。

两者不能用一个“像不像”结论合并。

## 3. 创意模板与复杂特效

手册展示广告、电影片段、视觉穿梭、服装切换、图形与字体转化等结构参考。

只学习以下抽象结构：

- 开场钩子；
- 画面节奏；
- 转场机制；
- 镜头语法；
- 特效的触发与结束条件；
- 品牌信息出现位置。

不要复制他人的角色、品牌、广告词、镜头序列或完整创意表达。

## 4. 剧情补全

手册展示从漫画、分镜脚本、图片组和声音发散成短片。

用于“完全按照剧本”项目时必须降权：模型只能补充表演、时间和摄影细节，不得补写新剧情、改变事件顺序、关系或台词。创意补全只有在用户明确授权时才启用。

## 5. 声音、对白、语言和方言

手册案例涉及：

- 参考视频中的说话动作；
- 参考音色或旁白感觉；
- 背景音乐与音效；
- 情绪丰富的多角色对白；
- 多语种和方言表达。

审核至少分开：

- 说话者身份；
- 台词文本；
- 语言／口音；
- 嘴型与发声时点；
- 音色情绪；
- 环境音；
- 音乐；
- 是否出现未授权的新台词。

“能参考音色”不等于声音克隆授权。使用可识别个人声音前必须另行确认权利与平台规则。

## 6. 节奏参考与后期卡点

历史手册展示“图片提供内容，参考视频或音频提供关键帧位置和整体节奏”的组织方式。本库仅保留动作与剪辑节奏方法，视频生成阶段无配乐；配乐由后期统一组织。

验收点：

- 主要动作是否真正落在节拍上；
- 转场是否带来新信息，而非机械闪切；
- 画面景别与光影变化是否服务音乐段落；
- 生成片段是否遵守无配乐要求；
- 后期剪辑是否需要保留重新卡点的余地。

## 7. 情绪演绎

把“崩溃、愤怒、喜悦”拆成可见动作链：

```text
触发事件 → 视线变化 → 呼吸／停顿 → 面部与身体反应 → 接触动作 → 结束状态
```

参考视频只负责情绪强度与动作节奏时，必须明确不继承人物身份和场景。

## 通用验收卡

- 剧情：事件顺序、关系、台词是否被改写；
- 素材：每个 `@对象` 的职责是否兑现；
- 身份：人物、服装、道具、声音归属是否一致；
- 动作：重心、接触、速度、方向和结束姿态是否连续；
- 镜头：机位、景别、轴线、焦距与转场是否符合目标；
- 场景：结构、光线、时间和空间锚点是否稳定；
- 声音：说话者、台词、音画同步、环境音与配乐是否正确；
- 编辑：未指定区域是否保持；
- 合规：真人脸、声音、品牌、版权和平台规则是否满足；
