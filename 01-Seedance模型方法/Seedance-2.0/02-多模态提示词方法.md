# 多模态提示词的七块结构

资料性质：2026 年 9 月整理的使用手册学习笔记。以下是创作写法与当时的界面语义，不代表当前版本的功能保证。历史数量、时长和格式限制见[参数快照](../历史资料与待核实参数.md)。

## 手册的最小方法

手册明确建议：

- 多次 `@图片／视频／音频`；
- 说明每个素材的用途；
- 写清情绪；
- 写清时序；
- 写清各环节细节；
- 素材多时检查每个 `@对象` 是否标清，避免把图片、视频和角色搞混。

可压缩为：

```text
提示词 = @对象绑定 + 参考职责 + 时间顺序 + 动作／镜头／声音细节 + 保持项与禁止项
```

这是对手册案例的 `LOCAL_INTERPRETATION`，不是模型必须遵循的固定语法。

## 推荐的七块结构

### 1. 任务类型

先说是新生成、延长、编辑、融合还是模仿：

```text
任务：基于多参考素材新生成一段 12 秒视频。
```

### 2. 素材职责

```text
@图片1锁定角色A的外貌与服装，不参考背景。
@图片2锁定场景结构与光线，不参考人物。
@视频1只参考走位、动作重心和镜头运动，不继承人物身份。
@音频1只参考节奏和环境氛围。
```

### 3. 一句话目标

```text
角色A在雨夜走廊发现门后异响，克制地靠近并在门把手转动时迅速后退，现实电影感悬疑短片。
```

### 4. 时间线

```text
0–4秒：中景跟拍，角色A沿走廊缓慢前进，脚步变轻，视线始终看向门。
4–8秒：镜头小幅前推，门后传来一次金属摩擦声；角色停住，右手悬在门把手前，没有触碰。
8–12秒：门把手自行转动；角色重心后撤一步，镜头同步后拉，结束在角色与门同框。
```

### 5. 表演与物理

```text
情绪从警觉到确认危险，表情克制；动作由脚步、重心、视线和呼吸体现。人物不瞬移，手与门把手没有穿模，光源方向保持一致。
```

### 6. 声音

```text
仅保留雨声、脚步、呼吸和一次门把手金属声；无旁白、无新增对白。
```

声音约束：无配乐、无字幕，仅保留剧本所需对白、原有画外音与物理环境音；配乐在后期加入。

### 7. 保持与禁止

```text
保持角色外貌、服装、走廊布局和门的位置不变。禁止额外人物，禁止场景跳变，禁止新增道具，禁止字幕与水印。
```

## 参考职责的四种常用写法

| 目的 | 写法 |
| --- | --- |
| 完全继承 | “角色外貌、服装和配色完全参考 `@图片1`” |
| 只参考局部 | “只参考 `@视频1` 的镜头运动，不参考人物” |
| 参考片段 | “只参考 `@视频1` 00:02–00:05 的动作节奏” |
| 参考优先级 | “人物以 `@图片1` 为准，动作以 `@视频1` 为准；冲突时人物身份优先” |

手册没有定义正式优先级语法；这些是自然语言消歧方法。

## 连续动作

手册示例写法是明确过渡关系，例如：

```text
角色从跳跃直接过渡到翻滚，保持动作连贯流畅。
```

更可控的写法应同时说明：

- 前一动作的结束姿态；
- 过渡动作；
- 后一动作的起始姿态；
- 摄影机是否切镜；
- 接触、速度与重心是否连续。

模板：

```text
角色落地时右脚先触地、膝盖屈曲卸力；借落地惯性向右前方翻滚，肩背先接触地面；翻滚结束后左膝跪地抬头。全程不切镜，镜头保持侧后方跟随，速度连续，不出现瞬移或姿态跳变。
```

## 不要把案例堆成提示词

手册中很多案例同时包含复杂运镜、对白、特效、角色替换、音乐和多场景。它们适合展示能力边界，不适合直接作为所有任务的默认密度。

在当前入口允许的时长内，优先保证：

1. 一个明确叙事目标；
2. 一条可追踪的动作链；
3. 一套不冲突的素材职责；
4. 一个可验收的结束状态。

如果所有要求都重要，应拆成连续生成单元，而不是继续加句子。
