# Seedance 模型创作方法

围绕剧本、分镜和提示词，保留 Seedance 2.0／2.5 历史知识中可复用的完整方法与模板。

## 阅读入口

| 目标 | 入口 |
| --- | --- |
| 理解多模态参考、生成、延长和编辑 | [Seedance 2.0 方法](Seedance-2.0/README.md) |
| 编写人物、长叙事、时间轴与白模参考提示词 | [Seedance 2.5 方法](Seedance-2.5/README.md) |
| 分清当前选择与历史模型资料 | [模型选择与版本边界](模型选择与版本边界.md) |
| 查旧参数的出处和局限 | [历史资料与待核实参数](历史资料与待核实参数.md) |
| 了解整理依据 | [来源与证据说明](来源说明.md) |

先把剧本、事件顺序、人物关系、逐字对白和关键动作锁定，再选择模型与参考方式。容量上限不是创作目标，方法模板也不覆盖当前项目的明确决定。

## 本专题的声音约定

视频生成提示词均不要求配乐；保留剧本所需对白、原有画外音与物理环境音。配乐仅在后期剪辑加入。示例中的“无新增旁白”不删除剧本已有旁白。

## 资料状态

这里是经过脱敏和重组的创作知识，不是当前产品规格承诺。历史手册、说明截图、学习归纳和制作经验分别标注；具体项目正文、私人素材和运行记录不在发布范围内。
