## 一条实用的创作顺序

1. **明确故事与当前版本。** 区分已有剧情、允许修改的内容和不能改变的事实。改写授权与忠实拍摄是不同任务。
2. **建立人物和空间。** 参考图分别负责身份、服装、场景、状态、风格或动作，避免一张图承担互相冲突的职责。
3. **按事件拆段。** 用目标、刺激、行动、反应和结果决定段落，不为了凑固定秒数切断对白或关键动作。
4. **设计画面表达。** 先确定观众需要看见什么，再选择景别、机位、运镜、表演和节奏。
5. **写自包含提示词。** 让每段独立说明人物、地点、开场状态、动作过程、声音和结束状态；不把“接上段”当成完整描述。
6. **依据实际结果接续。** 计划状态与成片可见状态分开记录。看不见的信息保持未知，不用猜测填满连续性表。

不需要每次读取全库。短片、对白场景、动作段和第一人称场景可以采用不同写法；模板字段是选择工具，不是统一格式要求。

## 可直接使用的协作要求

```text
请根据我提供的当前采用剧本和参考资料完成本轮任务。

本轮只做：【剧本分析／改稿／分镜／提示词／局部返修】。
锁定内容：【剧情、人物关系、逐字对白、关键动作、服装和场景事实】。
允许修改：【明确列出范围；没有授权的内容不自行改动】。
目标风格与规格：【以当前项目为准，不继承其他案例】。

先说明当前段落的叙事任务与人物目的，再写可见的行为和画面表达。
参考素材分别注明负责身份、外观、场景、动作、机位或色光中的哪些信息。
每段提示词自包含，保留开场状态、动作因果、人物反应和结束状态。
对白保留发声者与原句；保留剧本所需的原有画外音和必要旁白。
视频生成无配乐，保留对白与物理音效，配乐只在后期安排。
信息不足时标明未知；方法建议、实际观察和最终采用分别记录。
交付完整可阅读版本，列出改动和保留内容，由创作者判断是否采用。
```

## 版本和内容边界

- 模型章节保留历史手册与说明材料中的方法，但**不把旧参数上限写成当前产品承诺**。参数和输入方式以实际使用界面为准。
- 通用经验不代替当前作品的决定；单个例子有效，不代表所有题材、素材和模型都能复现。
- 本库不含私人项目剧本、真实人物资料、私人素材、账号配置、API 接入知识或运行记录。
- 只整理学习归纳和通用模板，不打包书籍全文、私人录音、原始手册或第三方素材库。
