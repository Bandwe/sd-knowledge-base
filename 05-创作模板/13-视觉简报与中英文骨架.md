# 视觉简报与中英文骨架

## 视觉简报

```text
用途与读者：
一句话情境：
第一注意点：
人物身份与服装：
主要对象与关键道具：
空间与通道关系：
天气、光源与材质使用逻辑：
借用的参考设计：
不继承的参考内容：
本轮允许探索的变量：
必须保留的正确部分：
```

## 中文描述骨架

```text
画面用途：[为何需要这张图，与后续镜头的关系]。
情境：[谁在什么空间，为了什么目标做什么]。
核心视觉关系：[主体尺度、距离、接触、光线或视线中的关键关系]。
空间要求：[入口、主要对象、障碍、通道与人物位置，保证动作能发生]。
材料与环境：[受湿、磨损、反射、明暗与实际位置相对应]。
角色规则：[当前采用的身份、体型、服装、发型和物件]。
本轮只探索：[明确变量]。
保留内容：[已有结构、角色与光线关系]。
检查重点：[观众首先看见什么，人物正在做什么，空间是否支持动作]。
```

## English structure

```text
Purpose: [what this image communicates and how it supports the following shots].
Situation: [who acts, where, toward which goal].
Key visual relationship: [specific scale, distance, contact, light or gaze relationship].
Spatial requirements: [entrances, main objects, obstacles, passages and character positions that support the action].
Materials and environment: [wetness, wear, reflections and lighting follow plausible location and use].
Character rules: [preserve the selected identity, proportions, clothing, hairstyle and carried objects].
Variable for this iteration: [the specific variable being explored].
Preserve: [the structures, character features and lighting relationships that remain fixed].
Review focus: [the first point of attention, the action and whether the space supports it].
```

文字骨架要配合具体事实和参考，不保证单靠文字就能保持空间一致。此模板是通用归纳，不是任何参考作者的原始提示词。
