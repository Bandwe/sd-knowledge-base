# 创作模板

复制需要的模板，填写当前确定事实，删除无用行。模板帮助组织信息，不要求每个项目都建齐全部文件。所有示例均为空白或通用占位，不含私人剧本。

| 阶段/问题 | 模板 |
|---|---|
| 确定一段内容与边界 | [单元计划](01-单元计划.md) |
| 分配图片、视频与声音参考 | [参考职责卡](02-参考职责卡.md) |
| 从计划到实际可见状态 | [连续性状态表](03-连续性状态表.md) |
| 单镜头、动作线简单 | [连续描述 TXT](04-单镜头连续描述.txt) |
| 多镜头、对白或动作接点明确 | [时间轴 TXT](05-多镜头时间轴.txt) |
| 攻防、发力与后果 | [动作因果卡](06-动作因果与受力卡.md) |
| 两人接触、传递与持物 | [双人互动卡](07-双人互动与持物卡.md) |
| 场景色彩与光源关系 | [色光卡](08-场景色光卡.md) |
| 空间或运动较复杂 | [白模预演卡](09-白模预演卡.md) |
| 只改灯光、材质等局部问题 | [局部视觉修改 TXT](10-局部视觉修改.txt) |
| 反馈转成修改与比较 | [返修记录](11-返修与版本比较.md) |
| 保住原声并交接后期 | [声音交接](12-声音与后期交接.md) |
| 组织一组能互相解释的图 | [视觉简报与中英文骨架](13-视觉简报与中英文骨架.md) |

视频生成阶段无配乐，保留剧本所需对白、原有画外音和物理音效；音乐在后期单独安排。计划、实际结果和最终采用分开记录。
