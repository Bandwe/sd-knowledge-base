# 单元计划

只填写当前段落需要的内容，不适用项删除，未知项保持未知。以下是创作组织模板，不是固定镜头数或秒数要求。

```text
单元名称与草稿版本：
原稿范围：
本段起始句/动作：
本段结束句/动作：
下一段不能提前发生的事件：

本段人物目标与阻力：
刺激 → 行动 → 对手/环境反应 → 状态变化：
允许细化的表演与镜头：
不可改动的剧情、对白、人物关系和关键动作：

采用的参考与各自职责：
开场人物、场景固定结构、距离与朝向：
摄影机侧、屏幕方向与视线：
关键道具数量、持有人、手侧、落点：
伤势、服装与其他必须延续的状态：

自然对白所需时间及估算依据：
动作与反应所需时间：
计划时长与切点理由：
结束时希望停住的可见状态：
与前后段的声音接点：
无配乐，保留所需对白、原有画外音和物理音效。

仍待确定的事实及其影响：
```
