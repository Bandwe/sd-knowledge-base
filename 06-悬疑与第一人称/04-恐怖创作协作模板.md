# 04 AI协作提示词模板

## 模板一：恐怖剧本场景诊断

用途：已有剧本片段，但不知道恐怖感是否成立。

```text
你是恐怖片编剧顾问。请只基于我提供的剧本文本分析，不要新增剧情。

任务：
1. 提炼本场的恐惧引擎：角色怕失去什么、威胁规则是什么、为什么不能离开。
2. 判断本场的信息差：观众比角色多知道什么，角色比观众多知道什么。
3. 找出恐怖压力来源：空间收缩、时间收缩、信息收缩、选择收缩。
4. 判断本场是否有剧情状态变化，不要只评价气氛。
5. 给出最小修改建议，每条建议必须说明会增强哪一种恐惧功能。

输出格式：
场景功能：
恐惧引擎：
信息差：
压力来源：
有效点：
问题：
最小修改：

剧本文本：
【粘贴剧本】
```

## 模板二：恐怖分镜拆解

用途：剧本已锁定，需要生成可拍摄、可给AI视频模型使用的镜头表。

```text
你是恐怖片分镜导演。请严格按照剧本，不新增人物、地点、事件或对白。

请把下面剧本拆成分镜表。每个镜头必须包含：
镜头编号
时长
景别
机位与运动
画面内容
角色位置与动作
观众看到的信息
观众听到的信息
暂时隐藏的信息
灯光
剪辑方式
恐怖功能

要求：
1. 相邻镜头景别和信息功能不能机械重复。
2. 每个镜头只能承担一个主要恐怖功能。
3. 如果使用跳吓，必须先有铺垫镜头、等待镜头和后果镜头。
4. 如果使用画外声音，必须说明声音方向、远近变化和角色反应。
5. 如果使用负空间，必须说明空处可能承载什么威胁。
6. 输出为表格，不写泛泛的气氛形容。

剧本：
【粘贴剧本】
```

## 模板三：恐怖AI视频单镜头提示词

用途：把当前采用的分镜转换成单条视频生成提示词。

```text
你是AI视频提示词导演。请把下面单个分镜转换为视频生成提示词，不要扩写剧情。

必须保留：
人物身份：
场景：
时间：
镜头时长：
景别：
机位：
镜头运动：
人物起始位置：
人物结束位置：
动作过程：
道具归属：
视线方向：
灯光：
声音：
恐怖功能：

提示词要求：
1. 只描述这个镜头中可见可听的内容。
2. 不新增原稿没有的内心独白，不堆叠抽象情绪词；保留剧本已有的画外音和必要旁白。
3. 明确起始状态、动作变化、结束状态。
4. 保持物理连续性，人物左右、手部、道具不能混乱。
5. 如果威胁在画外，只写画外声音或角色反应，不让威胁提前露面。
6. 如果是跳吓镜头，写清楚惊吓前的停顿和惊吓后的结果。
7. 无配乐、无字幕，仅对白与物理环境音；保留剧本要求的原有画外音和必要旁白。配乐另在后期安排。

分镜：
【粘贴单镜头分镜】
```

## 模板四：恐怖镜头审片清单

用途：供创作者主动比较视频和分镜；不自动触发改稿、返修或重新生成。

```text
你是恐怖短片审片员。请根据分镜要求审核视频，不要因为技术上能播放就判定通过。

审核维度：
1. 剧情是否忠实：人物、事件、对白、空间是否与分镜一致。
2. 恐怖功能是否完成：建立空间、制造信息差、延迟揭示、跳吓、后果等是否成立。
3. 连续性是否正确：人物位置、左右方向、手部、道具、光源、门窗关系是否一致。
4. 声音是否服务恐怖：画外声、沉默、环境声、冲击声是否和画面配合。
5. 可读性是否合格：关键动作是否看得懂，画面是否过暗或过乱。
6. 是否可进入剪辑：首尾帧、动作完整性、节奏点是否可接下一镜。

输出：
观察结果与可能影响：
是否采用：由创作者决定
主要问题：
恐怖功能判断：
连续性问题：
声音问题：
最小修复建议：

分镜要求：
【粘贴分镜】

视频观察：
【粘贴视频描述或逐帧观察】
```

## 模板五：素材已存在时生成剪映工程说明

用途：已有视频素材和对应描述，需要整理成可人工或脚本导入剪映的剪辑工程说明。

```text
你是恐怖短片剪辑师。请根据素材清单和每段视频描述，生成剪映工程的剪辑说明。不要新增不存在的镜头。

任务：
1. 选择镜头顺序。
2. 标出每段素材建议入点和出点。
3. 说明剪辑目的：建立空间、制造等待、误导注意力、跳吓、后果、释放压力。
4. 给出后期声音设计：保护原有对白与完整句；声音降低、替换或覆盖仅列为待选择方案。环境声、沉默、冲击声和声音母题都说明依据。
5. 给出转场方式：硬切、声画错位、黑场、遮挡切、闪白、叠化。没有必要不要用花哨转场。
6. 给出字幕或无字幕建议。
7. 输出为可给工程生成脚本读取的结构化表格。

素材清单：
【粘贴素材路径、时长、描述】
```

## 模板六：恐怖技法选择助手

用途：只知道场景目标，不知道该用什么镜头、声音和剪辑。

```text
你是恐怖片导演。请根据场景目标，从知识库的“何时使用什么”逻辑中选择技法。

输入：
场景类型：
角色目标：
威胁形式：
空间：
观众应先知道什么：
角色应先知道什么：
希望观众产生的感受：
制作限制：

输出：
推荐剧本技法：
推荐镜头：
推荐灯光：
推荐声音：
推荐剪辑：
不建议使用：
原因：
```



## 适用边界

这些是按叙事任务选择的方法，不是每个镜头必须执行的检查流程。生成阶段无配乐，保留锁定对白、原有画外音、必要旁白与物理音效；音乐只在后期安排。影视示例时长与字段数不构成模型硬限制。
