# 通用影视方法到 POV 横屏互动影游的转换规则

## 1. 编剧层

直接保留“只写可见可听、人物受到刺激后做出可见行动、环境参与冲突”的原则。

在 POV 中，主角不可见的面部表情不能写入提示词。主角情绪必须改写为呼吸、心跳、耳鸣、吞咽、手抖、抓地、退缩、头部转动、步态和视野变化。敌人情绪通过凝视、嘴角、呼吸、手指压力、重心和接近速度表现。

## 2. 摄影机层

普通影视中的多机位由以下身体动作替代：

| 普通影视意图 | POV 替代方法 |
|---|---|
| 建立空间 | 主角抬头、起身、转向出口，手电逐段揭示空间 |
| 人物全身关系 | 目标位于两至三米外，主角视线沿身体自然上移 |
| 面部近景 | 目标主动靠近至半米以内 |
| 手部特写 | 主角低头或把手、道具带入双眼视野 |
| 反应镜头 | 主角的呼吸、头部后缩、视野停顿和手部动作 |
| 反打或回头 | 头部、肩胸和持灯手共同转动，身体行动轴保持连续 |
| 高低机位变化 | 仰卧、半坐、跪撑、站立、奔跑、受击和倒地造成眼位变化 |

摄影机不能独立于身体推拉、环绕、升降或漂移。

## 3. 横屏层

- 左右宽度表达威胁和出口的相对位置。
- 前景遮挡制造压迫和必要的隐藏续接。
- 中景保留当前身体互动。
- 背景只保留一个路线或威胁线索。
- 通过手电、门框、走廊和人物视线建立视觉中心，避免主体过散。
- 场景高位俯视图属于资产设计，不属于正片摄影机。

## 4. 互动层

- 可互动物必须在使用前建立位置、外形和可达距离。
- 手电、武器、钥匙、门把和机关需要连续的手部归属。
- 提示词必须明确玩家视线为什么转动，以及转动后能得到什么行动信息。
- 不能为了镜头漂亮让主角忽略眼前威胁或无原因观察环境。
- 互动影游不等于自动出现界面，界面只在当前作品明确需要时加入。

## 5. 单元层

生成单元用于组织制作，不必对应一次可见切镜。单元提示词必须自包含以下绝对状态：

- 摄影机空间位置、眼位、方向、俯仰、倾斜、速度和受力。
- 主角身体姿态、左右手、双腿、意识、伤势和生理声效。
- 敌人位置、距离、朝向、形态、左右手和接触关系。
- 道具位置、归属、朝向、亮灭和可达性。
- 固定环境锚点、行动轴、逃生方向和不可改变区域。
- 光源、色彩、声源方向、声音相位、开始遮挡和结束遮挡。

禁止用“上一段”“仍然”“原处”“同一个”代替绝对描述。

## 6. 一镜到底接缝

- 只使用真实物体全画幅遮挡、闭眼、昏厥、灯灭或进入完全暗区。
- 接缝前后匹配身体速度、摄影机方向、遮挡纹理、曝光、左右手、接触关系和声音相位。
- 遮挡期间人物和环境继续运动，不能在黑场中重置。
- 完整变身、复杂道具交接和终局攻击不得被接缝切开。

## 7. 光色声

- 色卡锁同一幕的光影、色调和色彩，不锁摄影机与动作。
- 环境微光负责空间层次，主行动光负责互动可读性。
- 低照度不等于背景完全无层次；光束外可以保留极弱轮廓，但不能看清路线。
- 心跳、呼吸、耳鸣和空间声音是 POV 叙事的一部分，必须跨单元连续。
- 默认声音句：`无配乐、无字幕，仅对白与物理环境音；主角心跳、呼吸、耳鸣属于主观生理声效。`

## 两层资产

### 全景视角场景图

先锁定一个物理空间的整体结构、固定物、出入口、材质、基础光色和行动路线。它是环境母版，不是正片镜头。

### POV 视角场景图

从已确认全景母版派生，锁定主角双眼在某个剧情时刻的眼位、方向、俯仰、前景遮挡、互动距离和手电可读范围。POV 机位变化不增加场景数量。

## 建议顺序

`全景图 → 结构确认 → POV图 → 全景与POV一致性检查 → 视频提示词`

禁止先生成大量 POV 图再反推空间，因为不同 POV 图容易出现门、墙、家具、走廊和道具位置互相矛盾。

## 编号建议

- `SC01-WIDE-01`：第一个物理场景的第一张全景主图。
- `SC01-POV-01`：第一个物理场景的第一个 POV 机位。
- `SC01-POV-02`：同一场景的第二个 POV 机位。

只有物理空间改变才递增 `SC` 编号；摄影机高度、方向和剧情状态改变只递增视角编号。

## 职责边界

- 全景图决定空间结构，POV 图不能修改结构。
- POV 图决定剧情机位，全景图不能强迫正片使用第三人称或高位视角。
- 色卡只锁颜色和光影，不改变全景结构或 POV 机位。
- 全景图和 POV 图都不得自动加入人物、界面、字幕、Logo 或水印。
