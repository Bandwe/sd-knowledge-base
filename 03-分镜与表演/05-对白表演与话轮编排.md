# 对白表演与话轮编排

学习日期：2026-10-26。来源：[Foyege弗曳哥的Seedance 2.5表演提示词教程](https://www.bilibili.com/video/BV1jLug6LEgp/)。适用于争执、挽留、隐瞒、道歉、身份揭晓等依赖对手反应的段落；不是所有对白都要抢话或结巴。

核心方法：不要只排列台词和情绪形容词，而要安排人物在对方的话语刺激下，如何争取、维持或放弃说话机会。人物目的决定表演，表演变化再决定镜头。

以下区分原教程方法与创作适配。作者的生成示例属于单案展示；本次未做付费复现，不据此保证任何模型能精确执行声音重叠或亚秒级时间码。仅保留方法转述，不复制原视频或转写。

## 一 教程中值得吸收的内容

| 原片位置 | 方法 | 可复用的要点 |
| --- | --- | --- |
| 约00:48至01:24 | 对白不只是轮流念句子 | 台词和口型正确，不等于存在真实交流；听者应因刚收到的信息发生变化 |
| 约01:24至01:56 | 设计话轮 | 安排当前主说者、准备接话的人、插入点、短暂竞争与退让，不必每句都等前一句完全结束 |
| 约01:56至02:28 | 区分抢话和沉默 | 想阻止对方继续表达，可以插入；尚未处理完新信息，可以先停住。二者服务不同人物目的 |
| 约02:29至03:22 | 有原因的言语不流畅 | 开口失败、重复、改口与沉默是不同表演选择；集中在人物此刻难以面对的内容上，而非平均撒进每句 |
| 约03:22至04:16 | 情绪与克制同时存在 | 作者示例结合身体泄露情绪、控制外露，以及仍想保护对方的目标，替代单一的哭泣结果描述 |
| 约04:16至04:49 | 分层组织提示词 | 分开场景人物的一致性、人物内在目的、对白时间轴，以及声音与镜头约束 |
| 约04:49至05:12 | 按节拍写，按问题改 | 每个节拍能对应目标、原句、触发、反应与话轮变化；发现问题时定位层级，不同时重写所有内容 |

作者把该写法称为“对白暗流编排”。这是本教程的方法名称，不把它包装成统一行业标准。

## 二 何时用什么

下表是结合教程与本库创作约定的应用建议，不是心理状态与某个动作之间必然成立的对应关系。这里讨论的是戏剧中的言语不流畅设计，不用于判断现实人物的性格或口吃原因。

| 当前戏剧任务 | 可考虑的表演 | 提示词该交代什么 | 不宜怎么用 |
| --- | --- | --- | --- |
| 急于纠正误解、阻止指责继续 | 在具体触发词之后插入 | 谁先说、听到什么、从何处插入、谁让出话轮、原句如何保留 | 尚未听见信息就反应；靠提高音量代替关系变化 |
| 想安慰，但对方仍在表达 | 试探性接话后退让 | 接话意图、短暂重叠、未获得话轮后的动作 | 所有安慰都强行盖过对方；听者突然静音 |
| 需要消化新事实 | 有内容的沉默 | 原动作在哪一刻停住，注意力落在哪里，何时重新有能力回应 | 拉长静止画面凑秒数；把人物写成没听见 |
| 想承认但难以开口 | 关键处的起句失败 | 意图已出现，发声如何未能完成，随后继续还是放弃 | 每个字都结巴；把重复音节当作唯一演技 |
| 急于确认自己的立场 | 重音，或已获授权的重复 | 语义焦点、立场变化与对方反应 | 未经允许给锁定台词添加一串重复词 |
| 想藏住真实目的 | 已获授权的自我修正 | 原意图被哪一刺激打断，怎样转回可公开表达的内容 | 为了“潜台词”另造秘密、身世或动机 |
| 痛苦但仍要维持关系 | 失控征兆与控制动作相抵 | 少量身体变化、人物如何掩饰，以及仍试图完成的关系行动 | 所有人都眼红、吞咽、低头；将强烈外放表演一概视为低级 |

正常说明、正式宣告、冷静审问、纪律明确的场合，也可以有清楚完整的轮流发言。教程批评的是没有目的和反应的机械念稿，不是“完整说话必然不真实”。

## 三 从心理到可执行表演

先用一句内部分析确定人物此刻想让对方做什么，例如留下、相信、停止追问、接受道歉。这个判断必须来自当前剧本，不能借表演设计新增剧情。

再把它压缩为观众能看到或听到的变化：

1. **刺激**：对方的哪个词、动作或眼神进入人物感知。
2. **反应**：当前动作、注意力、呼吸或发声出现什么变化；只选本镜头能辨认的一两项。
3. **控制**：人物试图压住、修正或掩饰什么，不把一串微表情同时叠满。
4. **关系行动**：他接下来是阻止、靠近、让步、确认，还是暂不回应。

原片的悲伤示例在画面中用“关心目标”，解说也谈到关系目标。本文泛化为“人物仍想怎样对待对方”，可包含保护、说服、拒绝或维持体面；这属于应用扩展，不意味着每场戏都要让人物关心对方。

同一个人可以在谈到自己时难以继续，在试图保护对方时突然说得清楚。变化有目标，往往比全程同一种哭腔或同一种紧张动作更有层次；是否采用由项目风格和当前剧情决定。

## 四 抢话如何写得清楚

优先使用事件锚点，而不只堆绝对时间码：

> 甲说到原句中的指定词后，乙才开始接话。甲不是瞬间消音；两人短暂重叠，随后按本场关系由指定一方让出话轮。听者的视线与原有动作接住这次变化。

这只是写法骨架，不能把“指定词”等占位符直接交给模型。正式稿要填入实际原句、准确触发位置和对应角色。

原片以提前约0.1秒、重叠约0.2秒示范控制目标，也展示过约0.1至0.3秒的写法。这些数字不是普遍标准，更不是模型精度承诺。文字稿先确保因果和顺序，精确声音接缝需要依实际成片处理；不能单靠移动音轨破坏可见口型。

锁定对白时尤其注意：

- 默认逐字保留台词，不把“更真实”当作删句、改口、添加重复字或吞掉关键线索的许可。
- 可以设计不增删字的起句前迟疑、已允许的句间停顿、听者反应；也要服从原定节奏和表演锁。
- 新增抢话、截断或语义次序变化如会改变对白呈现，应作为改稿方案，由用户决定；有明确授权的原稿则直接按原稿执行。
- “不要补完被打断的句子”只适用于原稿已经如此安排的句子，不是通用删词规则。

## 五 镜头配合表演

本节是分镜适配，镜头术语可结合[60条镜头选型](08-60条镜头语言选型与边界.md)按需选择。

| 需要观众读懂什么 | 可优先考虑 | 必须保留的信息 |
| --- | --- | --- |
| 两个人正在争取话轮 | 双人中景或可读的过肩关系镜头 | 两人的回应关系，不因每句切镜把重叠剪成排队 |
| 某句话改变了听者 | 反应近景，原说话人可继续在画外说话 | 仍是场内对白，不误标成内心旁白；人物必须先听到触发信息 |
| 克制正在失效 | 有选择的面部或手部细节 | 当前姿态、视线、泪痕和动作进度，切近后不能重新开始表演 |
| 权力、距离或退让发生变化 | 能看清相对位置的中景、全景或有动机的跟随 | 不凭镜头移动新增逼近、退后或越轴；动作来自已允许的调度 |
| 秘密刚被理解 | 允许一段有变化的持续镜头 | 停顿中仍有明确接收与判断，不用快速切镜提前替人物完成反应 |

声音重叠不是必须切镜的信号。镜头服务哪一方的信息变化，比“谁开口就拍谁”更重要。

## 六 可复用提示词骨架

四层结构是可选组织方式，不增加固定字段或逐秒写作要求。项目要求人物仅图号姓名、禁止声线或音量形容时，删去对应描述，只保留获准的信息。

```text
场景与连续性：已确定的地点、时段、人物绑定、站位及当前可见状态。
人物目的：本段甲试图完成什么，乙试图完成什么；依据原剧本，不新增秘密。

对白节拍：
说话者及逐字原句：填写当前采用台词。
触发位置：对方实际听到哪个词或看到哪个动作后发生变化。
可见表演：一至两个有因果、在本景别可见的变化。
声音动作：仅填写项目允许的停顿、重音或接话方式。
话轮与听者：继续、接入、退让或沉默；原句保留方式明确。
镜头：拍谁以及为什么在此刻保持、切换或移动。

结束状态：双方视线、动作进度和仍未解决的关系，不提前加入下段事件。
声音边界：无配乐、无字幕，保留原剧本对白、原有画外音与物理音效。
```

### 原创小例子 保留原句但消除念稿感

虚构情境：甲决定离开，乙想挽留却暂时没有说出口。只用于演示写法，不映射现有项目，也不是已测试模型稿。

```text
室内门边，甲握着门把手，乙在他身后，两人位置不变。
甲说：“我明天就走。”
乙听见“明天”时，原本伸向甲的手停在半途；没有立即接话。
镜头停留在乙的近景。她先看甲仍握着门把手的手，再抬眼看他，收回尚未碰到他的手，回答：“好。”
不要加哭泣或新的对白。停顿只承载这次从挽留冲动到收回动作的变化。
无配乐、无字幕，仅保留上述对白与房间的物理环境音。
```

这里的改进不依赖抢话：信息到达、动作受阻、关系选择和镜头注意点形成一个完整过程。已有项目只能使用剧本允许的等价动作，不能直接套入“离开”情节。

## 七 项目适配与效果边界

- 克制情感戏可优先参考反应、控制与关系目的；不把所有情绪压成低声哽咽。
- 争执与喜剧可参考话轮竞争；关键对白可懂度优先，不能用重叠掩盖剧情信息。
- 悬疑可参考接收新信息后的迟疑；不借迟疑擅自宣告人物有罪或早知真相。
- 风格化动画可采用更大的姿态变化；不直接继承教程的真人面部质感和电影色调。

后续用户要求比较实际生成结果时，可围绕声音是否按意图交接、身体与语言是否对应、切镜后情绪是否连续来定位问题；机器转写不能单独证明这些效果。按用户反馈修改相关层，不自动新增创意迭代或付费重试。

教程中的小云雀界面、30秒选项、风格库和示例规格属于当时演示，不成为其他项目或渠道的当前能力结论。知识已整理入库，效果尚需在获准的具体任务中检验。
