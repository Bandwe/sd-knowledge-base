# 情绪反应、眼睛与视线构图

2026-10-30｜专业资料归纳与提示词应用

一、资料支持的动画表演原则

1. 表情呈现角色处理信息的过程。先明确刺激及开场情绪，再设计一个主要情绪转折；不把所有五官变化与大幅肢体动作同时堆在一起。眼睛每次移动应有目标和停留，避免无目的漂移。
来源：Dana Boadway-Masson / Animation Mentor, Facial Animation 101
https://www.animationmentor.com/blog/facial-animation-101/

2. 眼部应作为整体设计。眼睑、眼眶及周围结构共同表达情绪；眼睑开合与视线朝向共同作用，不能只写瞳孔缩放。人的眉眼教学用于动物时，应依资产已有的眉脊、眼睑和头骨结构转换，不给动物凭空添加人类眉毛。
来源：Scott McWhinnie / AnimSchool, Animating the Eye Mask
https://blog.animschool.edu/2025/04/11/animating-the-eye-mask/

3. 眨眼有表演动机。可配合思考变化、转头或情绪收束，不按固定间隔机械眨眼。持续盯看同样可以表达紧张或专注，具体含义取决于情境。
来源：Shawn Kelly / Animation Mentor, Blink for a Reason
https://www.animationmentor.com/blog/blink-for-a-reason-acting-advice-from-ilm-lead-animator-shawn-kelly/

4. 保持姿态也可以有生命感。Moving Hold通过呼吸、重心、惯性余动等延续已建立的情绪，不等于随机摆头。惊住一瞬不必删掉，关键是它有刺激来源及后续变化。
来源：Shawn Kelly / Animation Mentor, Why All Animators Need to Master the Moving Hold
https://www.animationmentor.com/blog/why-all-animators-need-to-master-the-moving-hold/

上述资料包含三维动画教学；可迁移的是表演与可读性原则，不把案例渲染风格带入二维作品。以下写法为结合这些原则的制作应用，不是所有情绪唯一对应的科学公式，也不是已验证某视频模型必然执行成功的承诺。

二、实际提示词的简洁写法

每个关键反应写成：看见/听见什么 → 看向哪个目标 → 眼睑与嘴/吻部如何改变 → 头身如何接住 → 运镜如何揭示目标或反应。
例如：它看向画面左侧的对手，撑开的眼睑缓缓压低、微张的嘴合紧；头颈不再后缩，转为稳稳迎着对手。反打对方，视线朝右，接住这次目光。

画面中交代目标的左右及距离镜头远近；目标在画外时，后续反打、摇镜或转焦承担揭示任务。注视方向适当留空间；遮挡、强光、景深变化不盖掉本镜需要读懂的眼睛。镜头落点清楚时才切，不把关键变脸淹没在全程甩镜里。

情绪差异以当前角色性格和情境决定，可选写法：
- 震惊：突然撑开眼睑、下颌微松、头身短顿，再确认刺激；虹膜短颤只作特定夸张。
- 恼怒：目光锁定具体对象、眼睑压紧、吻部和颈部收紧，再采取行动。
- 尴尬：目光短避或下落，再刻意看回对手、重新撑起姿态；观众看见掩饰的努力。
- 嫌弃：上下打量后半压眼睑，移开视线、头身转离；不能和恐惧逃命共用一套动作。
- 委屈：眼睛仍追着想得到的对象，嘴/吻部松下、肩颈泄气，随后才出现剧本要求的哽咽或呜咽。

三、正反打与节奏（制作应用）

先建立谁在哪里、彼此朝向与距离，再用双方互补的视线方向组织正反打。较高或较低角色的视线高度也需匹配。正面近景不自动等于看镜头。
情绪高潮可安排：刺激者 → 接收者表情变化 → 刺激者确认对方反应 → 行动结果。每个短镜只承担一件可看懂的事。反应切镜承接同一声吼/同一次动作，不重新起吼或重新受惊。
快切集中在情绪交锋，完整躲避、接触、摔落或四散等决定因果的动作，保留足够空间与时间。具体0.6秒或1秒只是当次镜头预算，不作通用动画标准。
表情强弱应有变化；不要把所有角色、所有时刻都做成最大幅度。背景情绪图只在明确采用时使用，不能替代表情与动作本身。
