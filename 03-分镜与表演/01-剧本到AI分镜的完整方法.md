# Higgsfield剧本与AI分镜提示词方法整理

面向竖屏漫剧与连续叙事视频的实用参考

整理日期 2026年9月22日

Higgsfield资料中最适合迁移到漫剧制作的流程是：先把剧本拆成可见的戏剧变化，再决定用哪些镜头表达，建立人物与场景参考，最后为每个生成单元写清动作、摄影、声音和结束状态。导演分析可以充分，实际提交文本应只留下影响这一段结果的信息。

本文把官方文章、官方生成Skill和社区方法分开标注，重点回答三个问题：如何把剧本写成可拍的场面，如何组织AI分镜提示词，以及如何让不同镜头接成同一场戏。文末提供可复制模板和一段原创教学案例。

## 2 从剧本到视频的完整工作顺序

官方的两篇流程文章都把镜头规划放在生成之前：先整理剧本、分解场景和视觉节拍，再做镜头表或分镜图，之后才制作视频并剪辑。分镜阶段需要判断角色、空间、节奏和画面意图，而不只是收集好看的图。［S1、S2］

### 2.1 先分清四个层级

| 层级 | 要回答的问题 | 示例 |
| --- | --- | --- |
| 场景 | 这段戏在什么时地发生，人物关系发生什么变化 | 夜间修表铺，一人交还怀表，另一人拒绝收下 |
| 戏剧节拍 | 哪个信息、行为或判断改变了局面 | 她推表过去；他推回来；她停下离开的准备 |
| 镜头 | 观众在这一次连续观看中需要看懂什么 | 全景看距离；手部近景看物件归属；关系镜头看犹豫 |
| 生成单元 | 当前模型一次需要完成哪些画面和声音 | 一个连续镜头，或含明确切点的一组短镜头 |

以上定义是本文的工作划分。一个场景可以拆成多个单元，一个单元也可以包含多个镜头；镜头数量与生成次数分别统计。

### 2.2 逐层产生可检查的结果

1. 剧本层：确认原文、人物关系、事件顺序、场次及对白。
2. 场景层：写出本场开局、人物试图改变的事、转折和结束关系。
3. 节拍层：挑出真正改变信息或关系的时刻，判断哪些需要画面。
4. 分镜层：为每个镜头指定任务、机位、景别、动作、声音和时长。
5. 参考层：明确人物、场景、服装、道具、影调分别参考什么。
6. 提示词层：按模型输入方式组织，补齐这一单元的开场和结束状态。
7. 检查层：逐字核对白、连读空间与持物变化、核算时长，再看整段镜头节奏。

不必为每句台词单独配一个镜头。一个句子可以跨镜继续，也可以让声音留在画外，把画面给倾听者或正在发生的动作。

## 3 剧本应怎样写得更适合视觉制作

### 3.1 先区分新故事开发与锁定剧本改编

新故事开发可以讨论人物目标、冲突、转折、结尾和对白；已有锁定剧本时，分镜工作负责把原有因果表达清楚。人物关系、事件顺序、关键动作和原台词的修改需要单列为建议，由作者决定。

Higgsfield官方给出过“钩子、问题、解决、行动号召”的结构，它适合广告、讲解类视频和部分短故事。连续漫剧可以借鉴开场迅速建立冲突的思路，结尾则应服从本集剧情，例如悬念、关系变化或新信息，不必插入行动号召。［S2］

### 3.2 用场面变化组织一场戏

下面是本文用于剧本开发的工作模板。它把社区的目标、阻碍和节拍分析转成编剧可用的问题，但不代表Higgsfield有一套固定的长篇剧作公式。［C2］

```text
场次与时地：
本场开始时的关系：谁信任谁，谁占主动，谁知道什么。
人物当下目标：谁想从谁那里得到什么。
阻碍：对方、环境或已有事实为什么使目标难以完成。
策略：人物先尝试怎样影响对方。
转折触发：哪句原台词、哪个动作或哪条信息改变了判断。
策略变化：人物据此怎样改变自己的行为。
本场结束时的变化：关系、信息、位置或物件归属发生什么变化。
必须保留：关键动作、逐字对白、伏笔与下一场需要继承的状态。
```

目标应落在当前对手和当前处境上。例如“让对方收下怀表”比“渴望被理解”更容易组织动作；“渴望被理解”可以保留在人物分析里，用具体行为表现出来。

### 3.3 把心理描述转为可见事实

官方建议用摄像机能够看见的行为写行动句，例如人物停步、回望，而非只写内心状态。［S2］本文将这一原则扩展为三步：确定刺激，选择行为，写出对方如何接收。

| 剧本中的抽象表达 | 可以讨论的视觉表达 | 需要检查 |
| --- | --- | --- |
| 她想留下又不敢开口 | 物件递出后手仍停在桌沿，视线等着对方回应 | 行为是否符合既定剧情和性格 |
| 他被她的话触动 | 原本阻拦的手放松，改为扶住她的重心 | 变化是否发生在听懂之后 |
| 两人关系疏远 | 分坐桌子两端，中间留空，物件成为交流媒介 | 空间是否清楚，是否过度依赖冷色 |
| 她想掩饰恐惧 | 继续原本的劳动，但听见关键动静后短暂停顿 | 小动作是否与环境和任务有关 |

这些表达需要结合人物选择。同样的悲伤，在不同人物身上可能表现为继续工作、避开回答、靠近、退后或暂时沉默。

## 4 怎样写人物表演

### 4.1 分析留在导演层 行为进入画面层

OSideMedia表演Skill围绕目标、阻碍、策略、节拍和潜台词组织人物行为，也重视倾听、判断、呼吸、重心和人与人的距离。可借鉴之处是让动作由处境推动。［C2］

导演层可以写：“他不愿承认关心，却不想让她离开。”画面层应进一步指定：“他听完后先看桌上的怀表，再把怀表推回她停留的手边；她没有立刻收走。”

可按下列顺序选择必要信息：

1. 刺激：人物实际听见或看见了什么。
2. 注意对象：视线落在哪里，为什么此时关注它。
3. 判断：是否需要一个可读的停顿。
4. 行动：身体、距离、劳动或物件处理发生什么变化。
5. 对手反应：另一个人如何接收这个行为。

每镜不必把五项全部写满。只写对观众理解有用、并能在时长内完成的内容。

### 4.2 对话时让双方处在同一场戏里

倾听者应保留原有姿势、手中任务和视线关系。对方说话时，他可能先看物件，听到关键内容后再抬眼；也可能听完才停止手里的活。反应要有触发点，不能提前知道下一句。

人物反应不等于不停运动。紧张的等待可以只表现为一段没有得到回应的注视；若每镜都添加眨眼、吞咽、握拳和吸气，动作会争抢注意力。

### 4.3 让表演与摄影分工

当关键是“他把东西还给她”，先让物件移动和接触点可见。当关键是“她终于理解他的意思”，再决定是否需要面部近景。镜头选择由本次信息落点决定。

旁白、OS和VO要分别注明声源及可闻范围。角色只能对自己实际感知到的事件作反应；观众听见的内心声，不自动成为另一角色听到的对白。

## 5 怎样选择机位 景别与运镜

### 5.1 先给镜头一个明确任务

官方错误分析文章强调镜头应有具体用途，并要求复杂场景先交代人物和物件的相对位置。［S4］本文建议在选机位前先写一句：“这一镜让观众确认什么。”

例如：确认她把物件交了出去；确认对方听懂了遗物的意义；确认门口有人接近；确认两人的距离开始缩短。任务明确后，才判断拍全身、脸、手还是环境。

| 需要观众看清的内容 | 可选的镜头办法 | 容易遗漏的内容 |
| --- | --- | --- |
| 人物与出口、障碍的关系 | 全景或中全景，保留关键地标 | 只拍脸会丢失行动路线 |
| 话语引起的判断 | 倾听者近景或双人关系镜头 | 不要提前出现情绪结果 |
| 接触和受力 | 包含双方身体或接触点的连续镜头 | 拉、推、扶、抓的施力者和方向 |
| 重要物件转手 | 清楚的局部镜头，再回人物关系 | 谁原本持有，何时松手，落在哪里 |
| 人物被环境包围 | 适当留出环境面积，人物占比下降 | 依据本场任务决定是否需要环境全景 |

### 5.2 把运镜写成一条可执行路径

运镜需要起始机位、移动方向和终点画面。人物走位另写，避免把人物向左移动误写成摄影机向左移动。［C3、C4］

```text
摄影机起点：门内右侧，胸口高度，朝桌边两人。
起始构图：双人中景，女左男右，桌面在前景。
主运动：沿桌外侧缓慢前移半步，始终留在人物关系轴同侧。
终点构图：停在女主中近景，仍留男主肩部作关系参照。
焦点对象：女主的眼睛；不在句子中途改焦到背景灯。
```

短镜头优先安排一种清楚的摄影运动。确需组合时写明先后阶段和目的；固定机位也有表现力，不必用运动数量证明“电影感”。

### 5.3 竖屏应先检查身体与空间能否同时读懂

以下为竖屏项目适配：9:16中，两人横向并排容易让手、道具或出口被裁掉。可以使用前后层次、肩部参照和必要的中全景；手部动作关键时给出实际裁切范围。多人动作先确认谁位于前景、中景、后景，再选焦段。

不要只写“换角度”。应写摄影机换到关系轴哪一侧的哪个位置，人物在画面中的大小发生什么变化。相邻镜头按当前项目要求避免相似机位和景别；必要的重复用于动作匹配或叙事强调时，注明理由。

## 6 参考图与电影影调怎样写

### 6.1 分别固定人物身份和场景结构

官方一致性文章把人物与地点作为两类参考：脸相同，不代表窗、家具和光线方向也相同。场景参考要能显示结构与重要地标，多段制作还需要明确参考的继承方式。［S5］

本文建议用“参考用途”防止错误继承：

```text
人物参考：锁定同一张脸、体型与发型；表情按本场剧情改变。
服装参考：锁定当前衣服和配饰；不复制展示图的站姿与白背景。
场景参考：锁定原门窗、家具和通道；摄影机按本镜机位移动。
道具参考：锁定同一物件的形制和数量；多视图不生成多个实物。
影调参考：只继承色彩与打光关系；场景结构仍以场景图为准。
```

平台提供的参考图能力不能直接等同于百分之百身份或空间一致。跨镜仍需看实际结果，尤其检查受伤状态、手持物、服装细节和场景方位。

### 6.2 先确定关键画面 再描述运动

Cinema Studio旧版官方指南提出Hero Frame First：先确定关键静帧的主体、构图和光线，再进入运动设计。它适合帮助判断开场画面是否成立。［S6］

实际使用时，先看参考图是否已经足够清楚。如果已有确认图，重点写将发生的动作和变化；如图中缺少关键接触点或人物站位，则先补齐这些信息。是否使用首帧、尾帧或成功截图，由当前任务授权和具体平台能力决定。

### 6.3 把电影感拆成画面中的具体关系

官方提示词基础涉及主体、环境、摄影、光线与视觉风格；图生图侧重改动，图生视频侧重运动。［S3］下面是本文把这些要素用于前置词的写法：

```text
电影级影调。夜间修表铺，左后窗透入冷灰蓝雨夜环境光，桌面暖台灯从右下方照亮手和怀表，人物面部保留暗部层次。旧木桌反光柔和，皮肤保留自然纹理，暗部干净。窗框、台灯和桌面位置固定；人物前倾时遮挡台灯，在桌面投下移动的影子。高清，9:16竖屏，真人电影质感。
```

这类前置词要随资产变化：白天雪院、深夜火场和室内窗光各自有光源逻辑。不要把同一组青橙色、雾气、眩光和胶片颗粒复制到所有场景。

背景物理交互应由当前行为引起，例如衣袖接触桌面，承重使草铺下陷，门开启改变雨声远近。只保留相关反馈，避免把所有天气和粒子效果同时放入一个镜头。

## 7 根据任务选择提示词格式

### 7.1 单镜短段落

适合主体少、动作明确、只有一次摄影运动的片段。官方提示词基础提倡简洁、具体；其中“约200 tokens以内”是该参考的建议，不能泛化为所有模型和复杂多镜任务的硬上限。［S3］

```text
电影级影调。[时地、具体光源与材质]。[角色身份与当前状态]在[明确位置]。摄影机位于[位置和高度]，以[景别]拍摄，沿[方向]移动至[终点构图]。人物从[初始动作]开始，因[可感知刺激]做出[主要动作]，最后停在[结束状态]。环境出现[相关物理反馈]。无配乐、无字幕，仅对白与物理环境音；对白和原有画外音按剧本保留。
```

### 7.2 MCSLA结构

MCSLA是OSideMedia社区方法，准确展开为Model、Camera、Subject、Look、Action，即模型、摄影、主体、视觉风格和动作。它用于检查主要信息是否齐全；实际输入语法仍以模型和使用入口为准。［C1］

| 字段 | 填写内容 | 编写提醒 |
| --- | --- | --- |
| Model | 实际模型、文生或图生、支持的输入和时长 | 无需在画面提示词里反复喊模型名称 |
| Camera | 景别、机位、透视、运动与落点 | 描述观看方式和物理路径 |
| Subject | 谁出现、当前状态、与谁是什么空间关系 | 稳定身份与临时状态分开 |
| Look | 时地、光源、颜色、材质和视觉风格 | 从真实资产推导 |
| Action | 起始、触发、过程、结束及必要反馈 | 一段可完成的行为链 |

本文在用于叙事视频时另加声音和首尾连续性。无需为了保留英文缩写而改变可读的中文表达。

### 7.3 时间轴与镜头契约

精确对白、多人接触、重要道具转移和多镜连续剧情，适合用时间轴。renmu社区契约提供十二类检查信息，覆盖叙事任务、主体、外观、空间、动作、摄影、光线、表演、连续性、声音、风险和规格。［C4］

实际交付可合并为以下结构：

```text
电影级影调：[根据资产写出光源、方向、色彩、材质、时地]
规格：[画幅、时长、实际模型支持的清晰度]
参考职责：[每个已提供参考负责什么]
开场状态：[人物数量、站位、朝向、姿势、持物与已有状态]
声音：无配乐、无字幕，仅对白与物理环境音。保留剧本原有画外音和心声，并注明可闻范围。

对白时间线：
[起止秒数]｜[角色]｜[场内对白或原有画外音]｜[逐字原句]

镜头01 [起止秒数]
机位与景别：[摄影机位置、高度、朝向、画面裁切、轴线侧]
运镜：[起点、主路径、终点；固定则写固定]
画面与表演：[谁做什么、对谁反应、人物朝向和画面位置]
接触与环境：[本镜需要看清的接触、受力和反馈]
声音：[实际发声者、物理声源、跨镜对白如何连续]

后续镜头按同样方式写。
结束状态：[最后人物位置、姿势、视线、持物、环境状态及动作阶段]
```

### 7.4 把导演分析与提交文本分开

导演分析保留选择理由、待比较方案和来源。提交文本保留当前采用的画面要求，删除被替换的旧指令和重复解释。图生视频可以少写已清楚显示的静态外观，但关键身份、当前持物、空间关系和变化仍要清楚。

在有独立摄影、光线或节奏控件的平台里，先设置对应参数，再避免文本与控件相互矛盾。Cinema Studio 4.0官方页面把类型、时代、Tempo、摄影、光线和情绪控制分开介绍；这些控件名称和能力属于具体产品，不自动适用于其他制作入口。［S7］

## 8 连续分镜最容易出错的地方

### 8.1 状态继承要写到实物和身体

每个独立单元都要补齐模型需要的当前状态。只写“接上一镜”，无法替代实际站位与持物。

| 连续性项目 | 至少记录什么 | 常见错误 |
| --- | --- | --- |
| 身份与数量 | 谁在场，谁已出画，同一角色是否变身 | 把多视图当多人；变身后残留另一具身体 |
| 身体状态 | 坐卧、受伤、湿衣、呼吸、变形部位 | 切镜后突然站起、伤势消失 |
| 空间与轴线 | 固定地标、角色相对位置、镜头所在轴侧 | 换机位后左右翻转，移动过程缺失 |
| 持物与接触 | 哪只手持什么，何时接触、松手、落定 | 刀换手、耳环复制、物件回到旧位置 |
| 光线与环境 | 时段、光源、门窗状态、损毁进度 | 夜景变昼景，烧塌的屋顶复原 |
| 声音与信息 | 谁说、谁听见、对白是否跨镜 | 听者对口型，人物回应不可闻心声 |

这张表是本文对连续制作的适配，可与社区分镜组织法配合使用。［C3］

### 8.2 让关键接触经历完整过程

例如“他抓住她”至少要在必要画面里成立为：两人原有距离 → 他哪只手从哪里伸出 → 接触她哪个部位 → 她怎样受力 → 最终站位。不要只给抓住后的静止结果，再靠观众猜中间发生了什么。

物件转手同样要知道原持有者、交接位置、接收者的手和松手时点。复杂镜头可以先简化装饰性摄影运动，保留关系和接触过程。

### 8.3 剪接重复区按剧情需要使用

相邻片段可以共享短动作，例如手刚握住门把、人物开始转身，作为后期选择接点的余量。共享区的时间只计一次，不应连剪成两次开门或两次转身。具体重合长度由项目和动作决定，不能把某个案例的固定秒数推广到全部镜头。

共享画面应核对同一个动作阶段、同一手、同一物件和同一机位逻辑。跨地点或时间跳转可以直接切换，无需硬造共同动作。

## 9 对白 时间与声音

官方脚本制作文章给出过英语每30秒约60至80词的起始估算，同时要求实际朗读计时。这个范围适合初步排程，受伤、哭泣、停顿和动作都会改变时长。［S2］

用于当前项目时，先保留逐字对白与原有OS、VO，再给吸气、倾听、动作接触和转折留时间。中文每秒约3至5字也只能作为初算，不应要求所有情绪统一语速。

时间不足时按顺序处理：去掉不承担叙事的装饰动作，调整镜头长度，在完整语义和动作交接处拆单元。原台词的删改另列建议，不在提示词阶段自行执行。

所有视频生成提示词统一写：

```text
无配乐、无字幕，仅对白与物理环境音。保留剧本原有画外音与内心声，注明发声者及其他人物是否能够听见；台词不增删、不改写、不重复。配乐留到后期剪辑处理。
```

这是本库采用的制作约定。它与外部资料中自动加音乐、广告文字或音乐视频示例的设定分开处理。

## 10 原创案例 从剧本到可用提示词

本节是为讲解方法新写的独立片段，与任何现有项目剧情无关。它展示物件、倾听和人物距离如何承载情绪。

教学例子没有附人物或场景图片；如用于生成，需要先准备苏宁、林澈、修表铺和怀表的实际参考，并绑定对应输入。

### 10.1 教学剧本

夜，修表铺。苏宁站在旧木桌左端，将父亲的旧怀表推向站在右端的林澈。

苏宁：“你替我保管吧。”

林澈看了看怀表，没有收下，把它推回她停留的手边。

林澈：“你自己收好。”

苏宁低头看着回到手边的怀表，迟迟没有把手收回。林澈等着她，雨敲着窗。

### 10.2 先分析 再选画面

本场可理解为：苏宁试图通过托付遗物结束这次相见，林澈用归还物件保留她与这里的联系。这是教学例子的导演解释；若用于既有剧本，应先确认此解释没有越过原文。

可见的转折是怀表被推回。情绪设计围绕物件方向和等待展开，不需要同时增加哭泣、握拳和大幅移镜。

| 镜头与时间 | 叙事任务 | 画面办法 |
| --- | --- | --- |
| 01 0至3.5秒 | 建立两人和怀表的关系 | 双人全景，苏宁从左端把表推到桌中线 |
| 02 3.5至6.5秒 | 听清她的请求并等待答复 | 苏宁中近景，右手仍留桌沿，林澈肩部作参照 |
| 03 6.5至10秒 | 看见对方拒绝代为保管 | 手与怀表近景，林澈把表推回，原句在画外说完 |
| 04 10至15秒 | 让观众感受未结束的关系 | 双人中景，怀表已归她手边，两人都没有离开 |

### 10.3 可复制的15秒多镜提示词

```text
电影级影调。15秒，9:16竖屏，高清真人电影。夜间旧修表铺，后左窗透入冷灰蓝雨光，桌右暖台灯照亮手与怀表，脸部暗处有自然层次；旧木桌和金属反光柔和，暗部干净。

人物和空间：苏宁是左侧女性，林澈是右侧男性，人物形象按已提供参考。两人分站同一木桌两端，女左男右，相距一张桌宽。后窗、右台灯和桌子固定。摄影机全部留在两人连线的前景一侧。旧怀表只有一只，开场在苏宁右手指腹下的桌面，左手自然垂在身侧；林澈双手最初在自己一侧桌沿。

无配乐、无字幕，仅对白与物理环境音。对白只说一次：3.8至5.8秒苏宁说“你替我保管吧。”；8.0至9.5秒林澈说“你自己收好。”。雨敲窗、怀表擦过桌面、衣袖摩擦来自现场，不增加旁白。

镜头01 0至3.5秒 双人全景
摄影机在桌前中央稍偏右，腰高朝后窗方向，固定，手臂与桌面完整入画。苏宁用右手把怀表从自己面前推到桌面中线，再松开指腹，右手停在自己一侧桌沿。林澈的视线跟着表停下，身体不前移。表底与木桌真实接触，发出轻擦声。

镜头02 3.5至6.5秒 苏宁中近景
摄影机移到同一轴侧的林澈肩外，苏宁胸口以上入画，男主肩部留在右侧画缘；固定。苏宁看着林澈说完原句，句末目光没有离开他，等一个回应。桌上怀表和两人手的位置延续。

镜头03 6.5至10秒 手与怀表近景
摄影机仍在桌前同一轴侧，略高于桌面，斜俯拍桌中线至苏宁右手的范围；固定。林澈右手从画面右侧伸入，用指腹抵住表壳边缘，将同一只表沿原路推向画面左侧，停在苏宁右手边，再松开手。他在画外说完自己的原句。苏宁的右手没有提前抓表，只有袖口因微小前倾擦过桌沿。

镜头04 10至15秒 双人中景
摄影机回桌前中央稍偏左，胸高拍两人腰部以上及表的落点，缓慢后移半步，最终让桌子中间的空隙更清楚。苏宁先低头看手边怀表，再抬眼看林澈；她右手留在表边，没有再次推走。林澈右手已收回自己一侧，停下来等她。两人的位置不交换。只留雨声与呼吸，静停到结束。

结束状态：女左男右都站在桌边，怀表在苏宁右手旁，林澈双手位于自己一侧，没有离开、转身或新增动作。
```

### 10.4 图生视频时怎样压缩

若首帧已清楚表现人物、房间和桌子，可以压缩重复外观描述；仍需说明怀表的移动、对白声源、切镜和结束位置。下面是同一教学场面的单镜练习版本，画面组织与上方多镜版本不同，供比较使用。

```text
沿用参考图中两人的身份、衣服、旧木桌、后窗和右侧台灯。15秒，9:16，单镜到底，摄影机在人物连线前景侧，以能看清双手和桌面的双人中景固定拍摄。女左男右。苏宁右手把唯一一只怀表推到桌中线，松手后说“你替我保管吧。”，等待。林澈先看表再看她，用右手把表推回她右手边，说“你自己收好。”，随后收手。苏宁低头看回到手边的表，迟迟不拿走，最后抬眼看他。两人原位，表停在她手边。衣袖与桌面接触真实，物件不换形。无配乐、无字幕，仅对白与物理环境音；台词各说一次，保留窗外雨声、表壳擦木声和呼吸。
```

比较时看转折是否读得懂、物件移动是否成立、反应是否有时间，再决定哪种拍法适合当前素材；不能仅凭提示词长短判断优劣。

## 11 应吸收的方法与需要验证的说法

| 内容 | 本文采用方式 |
| --- | --- |
| 先剧本后镜头 一镜一个明确任务 | 作为规划原则，先看叙事功能 |
| 目标 阻碍 策略 节拍 潜台词 | 用于表演分析，不为凑次数新增情节 |
| 人物与场景分别提供参考 | 明确参考分工，生成后仍检查漂移 |
| 摄影机和主体都写起点过程终点 | 适用于重要运动与复杂接触，简单静态镜头可简写 |
| 200 tokens 200词 512字符 1800字等限制 | 分清单位、来源、产品版本和输入方式，提交前查实际限制 |
| 固定15秒 每段固定镜数 固定情绪变化次数 | 视为某个流程的组织选择，按当前项目和模型调整 |
| 某个很低的百分比验收门槛 | 不当成可复现的模型成功率，不据此自动批量重抽 |
| 首帧 尾帧 成功截图续接 | 作为可选控制手段，遵守实际平台能力与当前授权 |
| 参考图能保证身份或结构完全一致 | 视为产品目标或宣传表述，实际输出仍需核验 |

官方2.0指南、4.0介绍与社区旧文存在规格差异。例如2.0指南写过总长12秒与最多6镜，4.0介绍写到单次最长30秒。由此应把模型、版本、时长、参考数量和输入限制维护在单独参数表，不嵌进长期编剧规则。［S6、S7］

社区资料里出现的中文硬上限、固定镜数、验收百分比和强制英文等，也不替代当前任务规则。对效果的判断应来自同一剧本、同一资产和明确评价标准下的实际对照。［C1、C3］

## 12 可复用的分镜写作工作指令

下面可作为后续编写分镜时的工作提示。这是本文综合编写的模板，来源归属和项目适配见前文。

```text
根据我提供的剧本、当前人物场景道具资产、已确认修改和前序状态，制作可直接审阅的完整分镜提示词。

先确定工作模式：新剧本开发，还是锁定剧本的分镜改编。锁定模式保留剧情、顺序、人物关系、关键动作与逐字对白；对原文有疑义时查现有材料，无法确定的核心改动单列，不自行改写。

按场提取可见节拍：人物当下向谁争取什么，遇到什么阻碍，采用什么策略，哪条信息改变判断，场末有什么变化。不要把抽象情绪自动替换为握拳、吞咽、流泪或特写。

为每镜确定一个主要叙事任务，再选择景别、机位与运镜。写清摄影机的位置、高度、朝向、所在轴侧，以及运动起点、方向和终点。镜头应有变化，变化服从情绪与信息；相邻近似构图的必要重复说明理由。

每个独立生成单元都交代参考职责、人物数量、当前服装状态、站位、朝向、姿势、视线、手持物和环境状态。关键接触写明哪只手接触哪里、怎样受力、何时松开。状态变化必须有剧情依据和可见过程。

从图片资产分析并写出具体电影级影调：时段、光源位置、方向、颜色、明暗关系、材质与相关环境反馈。避免用电影感等空词代替画面事实。

对白按角色与时间线列出，保留原有OS和VO，说明可闻范围。说话者与镜头对象可以不同；倾听者对实际听到的信息作反应，不提前演后续结果。台词用朗读时间估算，保留停顿和动作时间；不足则调整时长或拆单元，不删锁定台词。

所有视频提示词无配乐、无字幕，仅对白与物理环境音。配乐仅在后期剪辑处理。

根据复杂度选择短段落、MCSLA或时间轴格式。导演分析与最终提交文本分开，清除重复、过时和相互冲突的指令。型号、规格、参考语法和字数限制以实际使用入口为准。

交付完整V01后，检查原文覆盖、对白归属、时码连续、人物和道具状态、轴线、环境损毁及收尾接点。整段连读镜头表，确认节奏与关系变化成立。列出确实存在的调度假设，等待创意反馈，不因文本检查通过自动生成或宣布采用。
```
