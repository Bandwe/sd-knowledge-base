# 生成声音与后期分工

本库的视频生成提示词不要求配乐；保留剧本所需对白、原有画外音和物理音效。配乐在后期独立决定，不能为了“无配乐”误删必要发声。

## 先定义谁在发声

| 声音 | 提示词需说明什么 |
|---|---|
| 场内对白 | 发声者、逐字原句、语气、声音与动作接点 |
| 场外对白 | 人物真实位置、是否仍属于同一空间、画面中谁能听到 |
| 内心声 | 主体、原句、其他角色不能直接回应的范围 |
| 旁白或原有画外音 | 原文类型、主体、是否跨镜持续，不擅自改成口型对白 |
| 闪回或特殊叙事声 | 所属时间/空间，以及是否进入现实人物感知 |
| 物理声 | 动作或环境来源、接触时刻、方位与必要强弱 |

OS、VO 等标签可能在不同稿件中使用不一致，应看实际语境。不能机械要求所有 VO 闭嘴或所有 OS 对口型。听者只对可感知的刺激反应；背景人物不添加未经剧本要求的可辨对白。

## 对白跨镜

先保住完整句和发声人，再决定画面是否切向听者、动作或物件。跨切镜持续的句子不重头复述；切换人物画面也不自动改变声源。需要动作先完成才能说的话，不能仅因剪辑方便提前发生。

原稿中的时间字幕先作为叙事信息保留在阅读稿，是否做后期字卡由项目决定；不直接让模型绘字，也不擅自新增解释旁白。场景固有文字、标识与后期字幕分别处理。

## 后期工作次序

1. 确认采用片段、可用区间、对白与原有声音接点。
2. 处理画面顺序和声画同步，保护完整原句。
3. 根据情绪、信息与动作需要决定音乐入点和出点。
4. 给必要留白，允许无配乐、仅环境声或局部安静。
5. 检查音乐是否抢台词、关键音效是否对准接触；实际听感以试听为准。

刺耳、太满、太小是不同问题；单纯降低总音量未必解决配乐密度。音乐授权与来源需另行核对，可播放或可下载不等于可用于任何项目。
