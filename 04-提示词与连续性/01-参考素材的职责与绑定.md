# 参考素材的职责与绑定

适用于角色定妆、场景设计、连续镜头和多模态提示词。参考越多不一定越稳定，关键是每份资料负责什么，以及哪些内容不应继承。

## 参考职责表

| 类型 | 用来约束什么 | 不应自动带入什么 |
|---|---|---|
| 身份图 | 面孔、年龄感、发型、体型、指定特征 | 旧服装、旧表情、拍摄布局 |
| 服装与状态图 | 当前服装、饰物、卷袖、污损、伤后状态 | 其他阶段的伤势或已废弃造型 |
| 场景图 | 门窗、通道、障碍、固定结构、材质 | 人物实际站位；空场不代表正式镜头无人 |
| 道具图 | 形制、尺度、数量、材质 | 自动增生第二件同款道具 |
| 色卡 | 主辅色、光源关系、明暗和饱和度倾向 | 色块、文字、排版、人物或构图 |
| 动作与白模 | 已选动作、路径、速度关系、站位和镜头 | 简模外观、灰材质、非目标角色比例 |
| 站位图 | 人物相对环境的位置、朝向、动作阶段 | 原机位、焦段、景别、画面错误 |
| 首帧图 | 经选定的开场构图与可见状态 | 整段都冻结在该姿态 |
| 声音样本 | 指定角色的声音特征 | 复述样本台词，给无台词人物添加对白 |

同一素材可承担多种职责，但要明确写出。指定一张完整形象图时，优先整体保持身份与服装；不要无依据拼接旧脸和旧衣。三视图是同一角色的多视角，不能变成画面中的三个人。

## 选择与整理

1. 核对本段真正需要的人物、场景、道具、声音与动作参考。
2. 同一角色存在多个版本时，以当前采用版为准，不按文件修改时间自动决定。
3. 为每份参考写“借用内容、解决的问题、不能继承的内容”。
4. 编号必须对应实际使用顺序。未提供的参考只可标为待补，不能在成稿中假装存在。
5. 若用了裁切或拼图副本，明确它与原图的关系；不要仅凭放大后的尺寸认定原生画质提高。
6. 先检查原图是否够用，再判断是否需要补图；简单静态构图不必为了流程完整而制作白模。

## 参考冲突处理

身份图与服装图冲突时写清各自职责；首帧图与空间图冲突时，应先确定当前起点，不能把两个相反站位同时交给模型。动作参考只展示局部手势时，不从画面外推测脚位。画面风格图可提供材质和色光方向，不意味着它的人物身份、道具或构图都要被复刻。

## 可直接使用的职责表达

```text
参考图1只负责人物甲的身份与当前服装，保持面孔、发型、体型和服装大形；不继承三视图排版。
参考图2负责房间的门窗、桌面、通道和光源位置，不规定人物站位。
参考视频1负责人物移动、关键接触与摄影机路径，不继承简模材质。
本段开场人物位置、视线与持物以正文描述为准；若参考之间仍有冲突，先列出冲突，不自行混合。
```
