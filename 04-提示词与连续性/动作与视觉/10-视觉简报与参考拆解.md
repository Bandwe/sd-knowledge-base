# 视觉简报与参考拆解

视觉资料应让接手者理解同一故事的角色、空间和行动，不能只是一组彼此无关的漂亮图片。以下是从既有原创练习中泛化的描述方法，不是参考作者原始提示词。

## 五项稳定信息

先写人物身份与服装、主要对象外形、关键空间关系、行动或问题发生位置、天气与主光。探索允许改变，但明确本轮改哪个变量以及理由，不同时悄悄替换整组设定。

| 简报问题 | 应写成什么 |
|---|---|
| 给谁看、做什么用 | 分镜、定妆、空间参考或其他明确用途 |
| 一句话情境 | 谁在何处为达到什么目标做什么 |
| 第一视觉重点 | 观众首先应注意哪个人、物或接触 |
| 空间规则 | 入口、主体、道具、障碍和通道的相互位置 |
| 材质规则 | 受湿、磨损、反射与使用区域的关系 |
| 不带入的内容 | 参考里的无关品牌、身份、装置或多余主体 |
| 本轮可探索项 | 机位、色温、姿态、道具位置等明确变量 |

## 每张参考要回答四件事

借用什么设计决定；它解决什么问题；哪些关系要保留；哪些东西不能带入。用“大入口与小人物形成尺度差，光线集中在正在处理的对象”这样的关系表达，代替只填“电影感、写实、高级”。

## 图组按用途选择

主场景回答人物与任务；反向视角回答空间能否从另一侧成立；角色多视角回答身份和服装；互动镜头回答手能否接触目标；近景说明关键细节；镜头小样说明新信息和首尾状态。

这些是候选用途，不是固定张数。没有用途的视图可以删去。二维拆件图能辅助沟通，但不等于已经得到可编辑三维模型。

## 把图像方法延伸到视频

为动作定义可见起止。例如“人物从门口走到桌旁，抬起灯照向指定物件，最后停住”。用小样判断动作和机位；空间、接触或运镜较难时再使用白模。图片区分设计、输入和执行问题，视频也同样适用。

成功后保留选择与修改理由，不能只剩最终画面。失败也不自动证明设计能力不足，应先看参考、描述和实际执行在哪一层偏离。
