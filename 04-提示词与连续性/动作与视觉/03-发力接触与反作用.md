# 发力接触与反作用

> 这是动作设计的可选方法库。文中的秒数、帧数、镜头数量与焦段均为具体风格示例，不是 Seedance 2.0／2.5 的硬性规格，也不保证模型逐帧执行。按锁定剧情、动作可读性和实际结果选择；精确变速与冲击帧放在后期。生成阶段无配乐，保留剧本所需对白、原有画外音和物理音效。

## 发力不是“拳头变快”

打击有力量感，通常来自四件事：

1. 重心先准备。
2. 力从地面或支点进入身体。
3. 身体各段按顺序传力。
4. 命中后有反作用和后果。

如果只有拳头飞快，身体不传力，观众会觉得像手臂贴图滑过去。

## 通用发力链

### 拳击/重拳

标准链条：

脚抓地 -> 膝微屈 -> 胯启动 -> 腰背旋转 -> 肩送出 -> 肘跟上 -> 腕锁定 -> 拳面接触 -> 肩肘腕回弹 -> 对方受力 -> 地面/空气/衣料延迟反馈。

分镜要点：

- 蓄势镜头看见脚、胯、肩的反向拧紧。
- 启动镜头看见后脚压地或蹬地。
- 命中镜头让拳面和目标接触点清楚。
- 余波镜头让攻击者不是完全无反应，至少有肩、腕、衣料或地面回弹。

AI提示词关键词：

```text
后脚抓地，膝盖微屈，胯部先启动，腰背旋转，右肩随后送出，拳面最后接触目标，命中后肩膀和手腕出现短促回弹，对手胸口受力后延迟后退，地面裂纹和尘土晚半拍扩散。
```

### 短距离寸劲

使用条件：

- 高手展示压缩发力。
- 角色距离极近，不能大幅拉拳。
- 要表现“全身力量集中到一点”。

动作链：

脚底摩擦锁住地面 -> 膝胯极小位移 -> 躯干整体前送 -> 肩肘腕同步短促锁定 -> 目标被推离或内伤式后退。

分镜要点：

- 不要夸张拉臂。
- 要拍脚底、胯、胸腔、拳面和目标受力。
- 重点不是拳头距离，而是全身质量参与。

### 踢击

标准链条：

支撑脚踩实 -> 髋部打开 -> 膝盖折叠或提起 -> 小腿甩出或整腿贯穿 -> 脚背/脚跟/胫骨接触 -> 支撑腿和躯干平衡 -> 被击者侧向或后向受力。

分镜要点：

- 必须看见支撑脚，否则踢击像漂浮。
- 横踢看髋部打开，直踢看膝盖提起，扫腿看重心降低。
- 命中后衣料、头发、护具、地面要有反应。

### 刀剑横斩

标准链条：

脚步调整 -> 肩胯同向或反向蓄势 -> 刀剑拉到路径起点 -> 刃线沿弧线通过目标 -> 接触或擦过 -> 刃线延长成速度线/残影 -> 收势。

分镜要点：

- 刃线方向必须清楚。
- 不要让刀剑在每个镜头随机换手。
- 近景拍接触，远景拍弧线和距离。

### 刺击

标准链条：

后脚推地 -> 身体前移 -> 肩线收窄 -> 肘腕锁直 -> 尖端先到 -> 身体随后压上 -> 目标后退或被钉住。

分镜要点：

- 刺击是直线威胁，适合用透视夸张。
- 镜头可沿刺击方向放大速度，但不能让尖端位置漂移。

### 下砸

标准链条：

高位蓄势 -> 重心上提 -> 武器/拳/脚过头顶 -> 下落加速 -> 接触地面或目标 -> 反震上返 -> 环境向外扩散。

分镜要点：

- 低机位和高机位都可用：低机位强调压迫，高机位强调落点和范围。
- 命中地面时不要让碎石和尘土同时爆开，最好分层延迟。

### 冲刺撞击

标准链条：

前倾 -> 脚步频率变快 -> 身体压低 -> 肩/肘/膝/武器作为撞点 -> 接触瞬间停顿 -> 双方质量对抗 -> 一方被推出。

分镜要点：

- 冲刺前给方向。
- 中途用残影或速度线，但接触帧必须清楚。
- 撞击后用拉远或侧面镜头展示位移结果。

## 击飞位移时长与力量读感

一条历史局部观察：把“拳后分离到撞墙”整体分配较长时间，生成结果可能变成持续推压或均匀后退。可先检查位移与环境后果是否混用同一时段；这不证明所有力量问题都由时间分配造成。

24fps下的动漫化重击建议：

1. 拳面接触：2至3帧，只证明接触点。
2. 受击点压缩与身体弹离：3至5帧，拳胸立即出现空隙。
3. 近距离飞向墙体：4至8帧；接触到到墙总计约0.25至0.35秒。
4. 撞墙和墙体破坏：10至20帧，凹陷、裂纹、碎石、粉尘分层展开。
5. 受击余波和结果：另开镜头，不占用击飞位移时间。

不同观感：

| 目标观感 | 接触后到达障碍物 | 读感 |
|---|---:|---|
| 持续推力、被逼退 | 0.8至1.5秒 | 重、慢、双方可能仍接触 |
| 爆发重拳击飞 | 0.25至0.45秒 | 瞬时释放、拳胸快速分离 |
| 超人式动漫冲击 | 0.12至0.30秒 | 可加抽帧或单向残影，必须保留到墙结果 |

AI提示词写法：

```text
拳面接触只保留2至3帧，下一动作立刻出现拳胸空隙；被击者在约0.3秒内跨过4米撞上石墙，飞行位移不慢放、不均匀拖长。撞墙后另用约0.6秒展示墙体先凹陷、再开裂、碎石飞出、粉尘翻卷。
```

审查时必须把“接触持续时间”“拳胸分离时间”“到墙时间”“墙体破坏时间”分开测量。不要只写整个结果镜头总时长。

## 命中点的六帧逻辑

以 24fps 或 25fps 为参考，强命中可按下面思路设计：

1. 蓄势帧：身体压缩或反向拧紧。
2. 启动帧：力从脚或支点进入身体。
3. 速度帧：肢体或武器拉伸、残影、速度线。
4. 接触帧：接触点清楚，最好短暂停住。
5. 冲击帧：黑闪、白闪、反色、墨线、星爆、冲击波。
6. 余波帧：双方身体和环境开始分层反应。

不是每次命中都要六帧全用。小命中只用 3 到 4 项，大招才完整使用。

## Hit Stop

Hit stop 是命中瞬间的极短停顿。

何时使用：

- 关键重击。
- 破防。
- 武器相撞。
- 终结一击。
- 观众必须读懂接触点。

怎么使用：

- 角色剪影、接触点、关节角度保持不变。
- 特效可继续扩散，但主体不要漂移。
- 一般只要 2 到 6 帧。短视频里过长会拖节奏。

禁用：

- 每次小拳小脚都停。
- 连续技中每一下都停。
- 角色位置不清楚时直接停。

## 反作用

动作可信的关键是双方都受力。

攻击者反作用：

- 手腕回弹。
- 肩膀震动。
- 脚底滑半步。
- 衣料/头发延迟摆动。
- 武器嗡鸣或震颤。

被击者反作用：

- 受击点先变形。
- 躯干随后后仰或旋转。
- 脚步延迟失稳。
- 手臂或武器被震开。
- 最后才飞出、倒地或跪下。

环境反作用：

- 地面先下陷，再裂开，再碎石飞起。
- 水面先压平，再翻起，再落下。
- 烟尘先被压缩，再开洞，再回卷。
- 光效先爆亮，再衰减，再留下余弧。

## 发力审查清单

- 是否看见支点：脚、墙、地面、抓握、空中反推来源。
- 是否看见蓄势：压缩、后拉、转胯、下沉、吸气。
- 是否看见传力顺序：不是所有部位同时动。
- 是否看见接触点：拳/脚/武器和目标没有被特效遮住。
- 是否看见反作用：攻击者和被击者都有受力。
- 是否看见余波延迟：环境不是同时爆炸。
- 是否符合角色身份：高手动作短，力量型动作重，速度型动作轻快，巨兽动作慢但范围大。
