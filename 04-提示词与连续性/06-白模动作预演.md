# 白模动作预演

白模用于表达动作、站位、视线、接触、运镜和节奏。它先解决“怎么发生”，最终外观可另由角色、场景和材质参考约束。简单静态镜头无需为了流程完整做预演。

## 选择合适精度

| 需要看清的内容 | 最低有用表达 |
|---|---|
| 远中景站位与移动 | 有体积的头、胸腔、骨盆和分节四肢，人物用可区分的灰度 |
| 朝向与目光 | 鼻向或头部方向标记；必要时加眼睛与眉毛 |
| 表情近景 | 粗略眼、眉、嘴形、头部倾斜和停顿，不必先做写实皮肤 |
| 握持、翻转小物、抓握 | 独立手指、物件厚度、接触位置与脱离时间 |
| 大衣或长发遮挡 | 保留影响轮廓与遮挡的大块，不必做微褶皱与发丝 |
| 场景通道与障碍 | 门、柱、桌、地面等体块，尺度足以支持动作 |
| 特效参与动作 | 保留路径、触发点、范围与接触时刻；装饰颗粒可后置 |

火柴人可用于早期草稿，但大透视、遮挡、接触和眼神通常需要更多体积信息。低精度可以减少建模、材质与渲染工作，不能省掉动作设计。

## 检查动作关系

姿势名称不等于姿势成立。交腿要看大腿是否跨过身体中线、搭在哪条腿上、支撑脚和悬空脚分别在哪里；抬高一侧膝盖不自动等于完成交腿。抓握要看手指是否接触同一物体，不能仅凭手臂朝向判断。

先看全身或侧前方是否能证明支点、重心、关键接触，再看目标机位的可读性。局部特写看不到的关系，保留未知。相机移动、人物移动、物件移动、切镜和特效变化分别标注，不把画面所有变化统称为运镜。

## 从参考片复建

可以提炼可见构图、屏幕轨迹、关键姿势、切点与速度关系；不能从压缩成片唯一反求三维相机、真实焦距和深度。黑背景中物体变大可能来自物体接近、相机变化或切镜，应区分观察与推断。

输入只保留需要的单一预演画面。上下对照、讲解字卡、平台片尾和无关文字不应变成故事画面的组成部分。动画预演与最终成片相似，也不能凭外观反推使用了哪个模型。

## 参考分工

```text
预演视频只约束人物站位、动作起止、关键接触、镜头路径和切点。
角色图负责身份、当前服装与外观；场景图负责环境外观。
不要把灰色简模、辅助线或预演标记保留到最终画面。
正文补充预演未表现的表情、声音与材质；不重复改写已经清楚的动作。
```

建议先选择一段包含目标难点但能独立理解的短片段，核对姿态、接触、视线和镜头，再扩展复杂互动。预演文件技术可用不等于生成模型已经证明能跟随，实际保持程度需要看输出。
